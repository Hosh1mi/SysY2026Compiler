SysY Compiler Wiki

一个面向 SysY 语言的编译器，支持前端解析、中端优化和 ARM64 后端代码生成。

项目简介

本项目是一个 SysY 语言编译器，采用经典的三阶段编译器架构，将 SysY（C 语言子集）源代码编译为 AArch64 (ARM64) 汇编。使用 C++17 编写，Flex/Bison 完成词法与语法分析， 自研 SSA 形式中间表示 (IR) 承载 25 个优化 Pass，最终通过后端生成高效的机器指令。

技术栈

C++17 · Flex · Bison · CMake · AArch64 · SSA IR · Docker
