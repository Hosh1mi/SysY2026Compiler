前端

Flex 词法分析 + Bison 语法分析 → AST → GenIR（Visitor 模式）→ SSA IR。

词法分析

词法分析器由 Flex 生成（src/frontend/lexer.l），负责将源文件转换为 Token 流。 同时追踪行号和列号（yylloc），用于错误定位。

Token 分类

类别示例
关键字int float void const return if else while break continue
标识符[A-Za-z_][A-Za-z0-9_]*
整数字面量十进制、十六进制（0x1F）、八进制（077）
浮点字面量十进制浮点、十六进制浮点（0x1.Fp3）
运算符+ - * / % >= <= == != && || !
注释// ...（单行）、/* ... */（多行），直接丢弃
调试模式

编译时定义 -DDEBUG_LEXER，lexer 会将每个 Token 输出到 stderr，包含名称、文本和位置信息。

语法分析

语法分析器由 Bison 生成（src/frontend/parser.y），采用 LALR(1) 解析。 解析过程中直接构建 AST 节点，解析完成后全局变量 root 指向根节点 CompUnitAST。

SysY 语法结构：

CompUnit  → (Decl | FuncDef)*
Decl      → ('int' | 'float') ['const'] Def (',' Def)* ';'
FuncDef   → ('int' | 'float' | 'void') ID '(' [FuncFParams] ')' Block
Block     → '{' BlockItem* '}'
Stmt      → LVal '=' Exp ';'
          | [Exp] ';'
          | 'if' '(' Cond ')' Stmt ['else' Stmt]
          | 'while' '(' Cond ')' Stmt
          | 'break' ';' | 'continue' ';'
          | 'return' [Exp] ';'
          | Block

AST 设计

所有节点继承自 BaseAST，通过 Visitor 模式解耦遍历逻辑。 Checker（语义检查）和 GenIR（IR 生成）各自实现 Visitor 接口， 无需修改 AST 节点本身。

节点层次

类别节点类
顶层CompUnitAST
声明/定义DeclAST DefAST InitValAST FuncDefAST FuncFParamAST
语句StmtAST（STYPE 枚举区分类型）BlockAST ReturnStmtAST
表达式AddExpAST MulExpAST UnaryExpAST PrimaryExpAST LValAST NumberAST CallAST
比较/逻辑RelExpAST EqExpAST LAndExpAST LOrExpAST

语句类型枚举

enum STYPE { SEMI, ASS, EXP, CONT, BRE, RET, BLK, SEL, ITER };
// SEMI=空语句  ASS=赋值  EXP=表达式  CONT=continue  BRE=break
// RET=return   BLK=块    SEL=if选择  ITER=while循环

类型枚举

enum TYPE { TYPE_VOID, TYPE_INT, TYPE_FLOAT, TYPE_BOOL };

扩展：向量类型支持（计划中）

后续计划为 SysY 语言添加 向量类型（类似 C++ 的 std::vector）， 需要贯穿整个编译流水线。新类型的添加路径如下： 

前端
  lexer.l       新增 vec 关键字 Token
  parser.y      扩展类型声明语法：vec<int> v;
  ast.hpp       新增 VecTypeAST 节点，TYPE 枚举加入 TYPE_VEC

IR
  type.hpp      新增 VecElemType（区别于固定长度 VectorType）
  irGen         处理 vec 的 push_back / pop_back / size / [] 操作
  instruction   新增或复用 GetElementPtr + 动态扩容 Call

优化
  Pass          向量化 Pass 需要识别 VecElemType 并跳过或特殊处理

后端
  codegen       vec 操作翻译为堆内存调用（malloc/realloc）或 NEON 指令（固定长度情况）
关键挑战

动态向量需要在 IR 层插入运行时的 malloc/realloc 调用， 并在后端生成对应的函数调用汇编；固定长度向量则可以直接映射到 NEON <4 x i32> 向量寄存器， 由 LoopVectorize 优化 Pass 利用。
