Peephole 优化

peepholeOptimize 是汇编生成前的最后一道优化，在机器指令的文本表示上进行局部模式匹配与替换。它采用 fixpoint 循环反复应用 17 条优化规则，直到没有任何规则可以再触发为止。

概览

// src/include/backend/arm64/peephole.hpp
void peepholeOptimize(std::vector<std::string> &lines);

函数接收汇编文本行（std::vector<std::string>），在行级别进行模式匹配。每次应用规则后标记 changed = true，循环重新开始，直到一轮完整的扫描没有任何改变。

void peepholeOptimize(std::vector<std::string> &lines) {
    bool changed = true;
    while (changed) {
        changed = false;
        for (size_t i = 0; i < lines.size(); i++) {
            // 依次尝试 17 条规则
            if (tryMachineSelfMove(lines, i, changed)) continue;
            if (tryMachineSwapMov(lines, i, changed)) continue;
            if (tryMachineForwardMov(lines, i, changed)) continue;
            if (tryMachineAndTBZ(lines, i, changed)) continue;
            if (tryMachineImmediateFold(lines, i, changed)) continue;
            // ... 其余规则 ...
        }
    }
}

解析辅助函数

由于 peephole 在文本行上操作，需要一组解析函数从汇编字符串中提取操作数信息：

函数用途
parseLine(line, op, args)将一行汇编拆分为操作码和操作数列表
splitOperands(str)按逗号分割操作数字符串，处理嵌套括号
parseMemOp(arg, base, offset)解析内存操作数 [base, #offset]
isLabel(line)判断一行是否为标签（以 : 结尾）
isBarrier(line)判断是否为跳转/返回指令

17 条优化规则

规则 1: tryMachineSelfMove — 自赋值消除

删除 mov wN, wN（源和目的相同的 mov 指令）：

// 匹配: mov wX, wX 或 fmov sX, sX
// 动作: 删除该行
// 示例:
//   mov w3, w3   → (删除)

规则 2: tryMachineSwapMov — 交换 mov 消除

检测相邻的交换 mov 对，保留第一条：

// 匹配: mov A, B; mov B, A
// 动作: 删除第二条
// 示例:
//   mov w3, w4    →   mov w3, w4
//   mov w4, w3    →   (删除)

规则 3: tryMachineForwardMov — mov 前向传播

当中间 mov 的源未被修改时，跳过中间寄存器：

// 匹配: mov tmp, src; mov dst, tmp (src 和 tmp 在两条 mov 之间未被修改)
// 动作: 第二条改为 mov dst, src
// 示例:
//   mov w10, w3     →   mov w10, w3
//   mov w4, w10     →   mov w4, w3

规则 4: tryMachineAndTBZ — AND+CBZ → TBZ

将 and + cbz/cbnz 或 and + cmp+b.cond 合并为单条 tbz/tbnz：

// 匹配: and wX, wY, #1; cbz wX, .L  (wX 不再被使用)
// 动作: tbz wY, #0, .L
// 匹配: and wX, wY, #1; cmp wX, #0; b.eq .L
// 动作: tbz wY, #0, .L

// 示例:
//   and w10, w3, #1    →   tbz w3, #0, .L_true
//   cbz w10, .L_true   →   (删除)

规则 5: tryMachineImmediateFold — 立即数折叠

将 movz + add/sub + mov 序列折叠为单条立即数指令：

// 匹配: movz wX, #IMM; add wY, wZ, wX
// 动作: add wY, wZ, #IMM (若 IMM 在 add 立即数范围内)
// 匹配: movz wX, #IMM; sub wY, wZ, wX
// 动作: sub wY, wZ, #IMM

// 示例:
//   movz w10, #42      →   (删除)
//   add w3, w4, w10    →   add w3, w4, #42

规则 6: tryMachineFoldAddSubMov — ADD/SUB 结果折叠

当 add/sub 的结果立即被 mov 到另一寄存器时，直接在目标寄存器上执行：

// 匹配: add wX, wY, wZ; mov wD, wX (wX 不再被使用)
// 动作: add wD, wY, wZ
// 示例:
//   add w10, w3, w4    →   (删除)
//   mov w5, w10        →   add w5, w3, w4

规则 7: tryMachineMulAddFusion — 乘加融合

将相邻的 mul + add/sub 融合为 madd/msub/mneg：

// 匹配: mul wX, wA, wB; add wD, wX, wC
// 动作: madd wD, wA, wB, wC
// 匹配: mul wX, wA, wB; sub wD, wC, wX
// 动作: msub wD, wA, wB, wC
// 匹配: mul wX, wA, wB; sub wD, wzr, wX
// 动作: mneg wD, wA, wB

// 示例:
//   mul w10, w3, w4    →   (删除)
//   add w5, w10, w6    →   madd w5, w3, w4, w6

规则 8: tryMachineStoreLoadForward — Store-Load 前向

连续的 str + ldr 访问同一地址时，ldr 可替换为 mov：

// 匹配: str wX, [addr]; ldr wY, [addr] (同地址)
// 动作: ldr → mov wY, wX
// 示例:
//   str w3, [x29, #-8]   →   str w3, [x29, #-8]
//   ldr w4, [x29, #-8]   →   mov w4, w3

规则 9: tryMachineRedundantAdrp — 冗余 ADRP 消除

删除重复的 adrp + add 全局地址加载：

// 匹配: adrp xA, sym; add xA, xA, :lo12:sym;
//        adrp xB, sym; add xB, xB, :lo12:sym; (同一符号)
// 动作: 删除第二组 adrp+add，将 xB 引用替换为 xA
// 限制: 两组之间 xA 未被重新定义

规则 10: tryMachineRedundantSubFrame — 冗余帧偏移消除

删除重复的 sub x17, x29, #N（帧偏移计算）：

// 匹配: sub x17, x29, #N; ...; sub x17, x29, #N (同偏移)
// 动作: 删除第二条 sub
// 限制: 两条 sub 之间 x17 和 x29 未被修改

规则 11: tryMachineZeroStore — 零值存储优化

将 movz wX, #0; str wX, [addr] 替换为 str wzr/xzr, [addr]：

// 匹配: movz wX, #0; str wX, [addr]
// 动作: str wzr, [addr] (32位) / str xzr, [addr] (64位)
// 示例:
//   movz w10, #0         →   (删除)
//   str w10, [x29, #-8]  →   str wzr, [x29, #-8]

规则 12: tryMachineDeadStore — 死 Store 消除

连续两次 store 到同一地址，第一次是死 store：

// 匹配: str wX, [addr]; str wY, [addr] (同地址，中间无 load)
// 动作: 删除第一条 str
// 示例:
//   str w3, [x29, #-8]   →   (删除)
//   str w4, [x29, #-8]   →   str w4, [x29, #-8]

规则 13: tryMachineMergeStores — 相邻 Store 合并

将两条连续的 str 合并为一条 stp：

// 匹配: str wA, [base, #off]; str wB, [base, #off+4]
// 动作: stp wA, wB, [base, #off]
// 限制: 两条 str 的基址相同，偏移差正好为 4（32位）或 8（64位）
// 示例:
//   str w3, [x29, #-16]   →   stp w3, w4, [x29, #-16]
//   str w4, [x29, #-12]   →   (删除)

规则 14: tryMachineMergeLoads — 相邻 Load 合并

将两条连续的 ldr 合并为一条 ldp：

// 匹配: ldr wA, [base, #off]; ldr wB, [base, #off+4]
// 动作: ldp wA, wB, [base, #off]
// 限制: 与规则 13 相同的地址连续性要求
// 示例:
//   ldr w3, [x29, #-16]   →   ldp w3, w4, [x29, #-16]
//   ldr w4, [x29, #-12]   →   (删除)

规则 15: tryMachineFallthroughBranch — Fallthrough 分支消除

如果无条件跳转的目标就是紧接着的下一个标签，删除该跳转：

// 匹配: b .L_next; .L_next:
// 动作: 删除 b 指令
// 示例:
//   b .L_end      →   (删除)
//   .L_end:       →   .L_end:

规则 16: tryMachineBranchThreading — 跳转链折叠

分支目标若是只含一条无条件 b 的 forwarder 块，将分支直接改跳最终目标。 适用于 b / b.cond / cbz/cbnz / tbz/tbnz； 沿 forwarder 链多级穿透（resolveForwardTarget），遇环放弃：

// 匹配: b.eq .Ledge_1   且   .Ledge_1: b real_target
// 动作: b.eq real_target
// 示例（LoopRotate 的 splitExitEdge 常产生此类残块）:
//   b.eq .Lmain_edge_1        →   b.eq main_label_42
//   .Lmain_edge_1:
//       b main_label_42

规则 17: tryMachineRemoveDeadForwarder — 不可达 forwarder 残块清理

跳转链折叠后遗留的 forwarder 块若不可达，删除其 label 与 b。 三个保守前提：label 是函数内部标签（.L* 或 函数名_*）、 函数内无任何操作数引用它、前一条可见指令是 b/ret（无 fallthrough 进入）：

// 匹配: (前一条为 b/ret) .Ledge_1: b target   且 .Ledge_1 无引用
// 动作: 删除 label 与 b 两行

规则分类

类别规则效果
冗余消除1 (self-move), 2 (swap mov), 9 (redundant adrp), 10 (redundant sub)删除不必要的指令
指令前向3 (mov forward), 6 (add/sub fold)减少中间寄存器使用
指令融合4 (and+tbz), 5 (imm fold), 7 (mul+add), 13 (merge stores), 14 (merge loads)合并为更强的指令
存储优化8 (store-load forward), 11 (zero store), 12 (dead store)减少内存访问
控制流15 (fallthrough branch), 16 (branch threading), 17 (dead forwarder)消除冗余跳转与残块

Fixpoint 收敛性

每条规则要么删除指令、要么将指令替换为更简单的形式，因此：

  • 指令总数单调不增
  • 每轮至少有一条规则触发才能继续下一轮
  • 有限指令序列保证在有限轮次内收敛

实践中通常 2-3 轮即可达到不动点。

示例：多规则级联

// 原始序列:
//   movz w10, #0           // 规则 11 触发
//   str w10, [x29, #-8]
//   str w3, [x29, #-8]     // 规则 12 触发 (dead store)
//   mov w11, w3            // 规则 1 不触发
//   mov w3, w11            // 规则 2 触发 (swap mov)

// 第 1 轮后:
//   str wzr, [x29, #-8]    // 规则 11 结果
//   str w3, [x29, #-8]     // 规则 12 触发 → 删除第一条 str
//   mov w11, w3            // 规则 2 触发 → 删除第二条 mov

// 第 2 轮后 (fixpoint):
//   str w3, [x29, #-8]
//   mov w11, w3
