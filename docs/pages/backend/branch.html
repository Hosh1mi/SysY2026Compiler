分支处理

PHI 节点解析、ICmp+Br 融合（csel / cbz / cbnz / b.cond）以及条件分支优化的完整实现。

概览

分支处理是代码生成中最复杂的部分之一，涉及三个核心机制：

  • PHI 解析 — 将 SSA 的 PHI 节点转化为边上的并行拷贝
  • ICmp+Br 融合 — 将比较+条件分支优化为单条 ARM64 指令
  • Csel 优化 — 将 if-else 菱形结构优化为条件选择

PHI 解析

preparePhi

在代码生成前预处理所有 PHI 节点，收集拷贝信息：

struct PhiCopy {
    BasicBlock *pred;  // 前驱块
    BasicBlock *succ;  // 后继块（包含 PHI）
    Value *src;        // PHI 操作数值
    int dstSlot;       // 目标栈槽
    Value *phi;        // PHI 节点本身
};
// 对每个 PHI：phi(val, predBB) → 在 predBB→succBB 边上插入拷贝

emitPhiCopies

在分支前插入 PHI 拷贝。实现了两种策略：

  1. 直接拷贝（快速路径） — 所有 PHI 目标都是已分配寄存器的标量值，且拷贝图无环。通过拓扑排序避免寄存器冲突。
  2. 分批暂存（回退路径） — 使用 r10-r15 暂存寄存器（最多 6 个一批），先批量加载源值，再批量写入目标。保证并行拷贝语义。

ICmp+Br 融合

当 ICmp 指令的唯一用户是条件 Br 时，emitBlock 调用融合逻辑：

// emitBlock 中的检测
if (inst->op_id_ == Instruction::ICmp) {
    auto br = dynamic_cast<BranchInst*>(*next);
    if (br && br->num_ops_ == 3 && icmp->use_list_.size() == 1) {
        if (tryEmitCSel(icmp, br)) continue;       // csel 优化
        emitFusedCmpBranch(icmp, br);               // cmp + b.cond 融合
        continue;
    }
}

emitFusedCmpBranch

将 ICmp + 条件 Br 融合为 ARM64 条件分支指令：

模式生成指令条件
cmp r, #0 + eq/necbz / cbnz常量为 0 且条件为 eq/ne
cmp r, imm12cmp + b.cond立即数 0-4095

PHI 拷贝与分支方向

当某个分支目标有 PHI 拷贝时，需要翻转分支方向——将"无拷贝侧"设为 fallthrough，"有拷贝侧"跳转到 trampoline 标签。当两侧都有拷贝时，选择拷贝数较少的路径作为 trampoline。

tryEmitCSel

将 if-else 菱形模式优化为 cmp + csel：

// Pattern A (if-else):
//   icmp → br trueBB / falseBB
//   trueBB:  1 inst + br mergeBB
//   falseBB: 1 inst + br mergeBB
//   mergeBB: phi(trueVal, falseVal)
//   → cmp; csel phi, trueVal, falseVal, cond; b merge

// Pattern B (if-then):
//   icmp → br trueBB / mergeBB
//   trueBB:  1 inst + br mergeBB
//   mergeBB: phi(trueVal, oldVal)
//   → cmp; csel phi, trueVal, oldVal, cond; b merge

安全限制：trueBB/falseBB 中的指令不能是 call、load、store、div、rem（这些有副作用或可能陷入）。

当 trueInst 和 falseInst 被分配相同物理寄存器时，需要先保存 trueInst 的结果到临时寄存器，避免 falseInst 覆盖。

tryEmitCCmpCSel

处理嵌套短路 AND 模式：

// icmp1 → br checkBB / merge
// checkBB: icmp2 → br trueBB / merge
// trueBB:  1 inst → br merge
// mergeBB: phi(trueVal, falseVal)
//
// 生成：cmp; ccmp; trueInst; cmp; ccmp; csel
// 两个条件同时满足时才选择 trueVal

条件码映射

ICmp 操作ARM64 条件码
ICMP_EQ / ICMP_NEeq / ne
ICMP_SGT / ICMP_SGE / ICMP_SLT / ICMP_SLEgt / ge / lt / le
ICMP_UGT / ICMP_UGE / ICMP_ULT / ICMP_ULEhi / hs / lo / ls
FCmp 操作ARM64 条件码
FCMP_UEQ / FCMP_UNEeq / ne
FCMP_UGT / FCMP_UGE / FCMP_ULT / FCMP_ULEhi / hs / lo / ls

示例

cbz 优化

// IR:
//   %cmp = icmp eq i32 %x, 0
//   br i1 %cmp, label %then, label %else

// 生成（无 PHI 拷贝）：
//   cbz w0, .Lfunc_then     // 直接跳转，省略 cmp
//   b .Lfunc_else

// 生成（then 侧有 PHI 拷贝）：
//   cbnz w0, .Lfunc_else    // 翻转：跳过拷贝，先到 else
//   mov w2, w5              // PHI 拷贝
//   b .Lfunc_then

csel 优化

// IR:
//   %cmp = icmp slt i32 %a, %b
//   br i1 %cmp, %max_bb, %min_bb
// max_bb: %v1 = add i32 %a, 1; br %merge
// min_bb: %v2 = add i32 %b, 1; br %merge
// merge: %r = phi i32 [%v1, %max_bb], [%v2, %min_bb]

// 生成：
//   add w10, w0, #1          // trueInst 内联
//   add w11, w1, #1          // falseInst 内联
//   cmp w0, w1
//   csel w2, w10, w11, lt    // 条件选择
//   b .Lfunc_merge
