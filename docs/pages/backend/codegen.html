代码生成

Arm64CodeGen 是后端的顶层入口，负责将 IR Module 翻译为 ARM64 汇编文本。整体流程包括全局变量分类、函数级并行代码生成、指令调度、Peephole 优化和最终输出。

概览

代码生成器 Arm64CodeGen 接收 IR Module 和输出流 std::ostream，经过 6 个步骤生成完整的 ARM64 汇编：

  1. 全局变量分类 — 将全局变量分入 .rodata（常量）、.data（有初值）和 .bss（零初值）
  2. 外部函数声明 — 遍历声明函数（当前为空操作）
  3. 收集非声明函数 — 筛选出需要生成代码的函数
  4. 并行代码生成 — 使用 std::thread 多线程并行生成各函数的汇编
  5. 输出 .text 段 — 拼接所有函数代码
  6. 输出数据段 — 按 .data → .bss → .rodata 顺序输出全局变量

类定义

class Arm64CodeGen {
public:
    Arm64CodeGen(Module *m, std::ostream &os);
    void generate();

    void setNoPeephole(bool v);        // 禁用 Peephole 优化
    void setEnableRegAlloc(bool v);    // 启用图着色寄存器分配
    void setNoSchedule(bool v);        // 禁用指令调度
    void setDumpMachineInstr(bool v);  // 输出 MachineInstr 调试信息

private:
    void emitGlobal(MachineModule &module, GlobalVariable *gv);
    void emitExtern(Function *f);

    Module *m_;
    std::ostream &os_;
    bool no_peephole_ = false;
    bool enable_regalloc_ = true;
    bool no_schedule_ = true;
    bool dump_machine_instr_ = false;
};

函数级代码生成

每个函数的代码生成在独立线程中执行，流程如下：

// 每个函数的生成流水线
MachineFunction machineFunc;
machineFunc.name = f->name_;
MachineEmitter emitter(machineFunc);

// 1. IR → MachineInstr（通过 Arm64FuncContext）
Arm64FuncContext ctx(f, emitter, enable_regalloc_);
ctx.generate();

// 2. 指令调度（可选，仅在启用寄存器分配时）
if (!no_schedule_ && enable_regalloc_) {
    MachineScheduler scheduler;
    scheduler.schedule(machineFunc);
}

// 3. Peephole 优化（可选）
if (!no_peephole_) {
    peepholeOptimize(machineFunc);
}

// 4. 调试输出（可选）
if (dump_machine_instr_) {
    std::cerr << dumpMachineFunction(machineFunc);
}

// 5. 序列化为汇编文本
results[idx] = printMachineFunction(machineFunc);

Arm64FuncContext 生成流程

Arm64FuncContext::generate() 是函数级代码生成的核心：

  1. 寄存器分配 — 若启用，运行 Arm64RegAlloc 图着色分配器
  2. PHI 预处理 — preparePhi() 收集所有 Phi 拷贝信息
  3. Prologue 生成 — 栈帧建立、callee-saved 寄存器保存、参数加载
  4. 块重排 — reorderBlocks() 贪心布局，最大化 fallthrough
  5. 指令发射 — 逐块逐指令翻译为 MachineInstr
  6. Epilogue 生成 — 恢复 callee-saved 寄存器、恢复栈帧、ret

Prologue 与 Epilogue

Prologue（emitPrologue）

// 1. 为所有 SSA 值分配栈槽（预扫描）
// 2. 计算帧大小 = align16(局部变量 + callee-saved 寄存器)
// 3. 发射：
//    stp x29, x30, [sp, #-16]!    // 保存帧指针和返回地址
//    mov x29, sp                   // 建立帧指针
//    sub sp, sp, #localSize        // 分配栈空间
// 4. 保存 callee-saved 寄存器（stp 成对保存）
// 5. 加载函数参数到寄存器/栈槽

Epilogue（emitEpilogue）

// 1. 恢复 callee-saved 寄存器（ldp 成对恢复）
// 2. add sp, sp, #localSize        // 回收栈空间
// 3. ldp x29, x30, [sp], #16       // 恢复帧指针和返回地址
// 4. ret                            // 返回

当函数没有局部变量且没有调用（needsFrame_ == false）时，省略 prologue/epilogue，直接 ret。

并行代码生成

编译器使用 std::thread 并行生成各函数的代码。线程数量为 hardware_concurrency() - 2（至少 1），在 Linux 上还会设置 CPU 亲和性避开核心 2、3：

unsigned numThreads = std::thread::hardware_concurrency();
if (numThreads <= 2) numThreads = 1;
else numThreads = numThreads - 2;

// 函数按 round-robin 分配到各线程
std::vector<std::vector<Function*>> partitions(numThreads);
for (size_t i = 0; i < funcs.size(); ++i)
    partitions[i % numThreads].push_back(funcs[i]);

每个函数的生成完全独立（各自的 MachineFunction、Arm64FuncContext），结果写入预分配数组 results[idx]，最终按原始函数顺序拼接。

全局变量输出

全局变量按类型分入三个段，输出格式：

// .data 段 — 有非零初值的全局变量
// .bss 段 — 零初值（使用 .zero 指令）
// .section .rodata — 常量（const 修饰）

// 每个变量的输出格式：
//   .global varname
//   .p2align 2
//   varname:
//   .word value        // 整数
//   .word 0xHEX        // 浮点（IEEE 754 位表示）
//   .zero N            // 零初值数组（N 字节）

数组变量递归展开每个元素；全零数组使用 .zero 指令压缩。

块重排（reorderBlocks）

贪心链式布局算法，最大化 fallthrough 以减少无条件跳转：

  1. 从入口块开始
  2. 优先放置条件分支的 fallthrough 目标（无 PHI 拷贝的一侧）
  3. 回溯到任意未放置的后继块
  4. 最终 fallback 到原始顺序中第一个未放置块
