Load/Store

Load/Store 子系统负责栈槽访问、临时寄存器分配、常量加载和全局地址计算。它提供了 load/store 系列 API，将 IR 值与物理寄存器之间建立桥梁。

概览

Load/Store 子系统由三部分组成：

  • 临时寄存器池 — 管理 w10-w16（整数）、s16-s31（浮点）、v0-v7/v16-v31（NEON）的分配与释放
  • Load 函数族 — 将 IR 值加载到临时寄存器（loadInt, loadFloat, loadAddr, loadVector）
  • Store 函数族 — 将寄存器值写回栈槽或寄存器（storeInt, storeFloat, storeAddr, storeVector）

临时寄存器池

寄存器类分配范围回退分配函数
整数 (w)w10 - w15w16allocIntReg()
地址 (x)x10 - x15x16allocAddrReg()
浮点 (s)s16 - s31s16allocFloatReg()
NEON (v)v0 - v7, v16 - v31v0allocNEONReg()

每次发射指令前调用 resetRegs() 将使用集合重置为预保留寄存器（由寄存器分配器确定的已分配物理寄存器），避免跨指令的寄存器泄漏。

栈槽访问

emitStoreRegMachine / emitLoadRegMachine

基于 x29（帧指针）的偏移访问，支持两种寻址模式：

// 短偏移（-256 ≤ off ≤ 255）→ 直接 ldr/str
//   ldr w10, [x29, #-8]
// 长偏移 → sub + ldr/str
//   sub x17, x29, #OFFSET    // 若 offset ≤ 4095
//   ldr w10, [x17]
// 超长偏移 → movz + sub + ldr
//   movz x17, #OFFSET
//   sub x29, x17 → x17
//   ldr w10, [x17]

成对访问（STP/LDP）

emitStorePairMachine / emitLoadPairMachine 使用 ARM64 的 stp/ldp 指令成对保存/恢复寄存器：

类型偏移范围对齐
32 位 (w/s)±2524 字节
64 位 (x/d)±5048 字节

超出范围时自动退化为两条独立的 str/ldr 或 sub + stp/ldp。

Load 函数族

std::string loadInt(Value *v);    // → wN / wzr（常量为 0）
std::string loadFloat(Value *v);  // → sN
std::string loadAddr(Value *v);   // → xN / xzr / adrp+add（全局变量）
std::string loadVector(Value *v); // → vN / ld1（常量向量）

每个 load 函数的优先级：

  1. 常量 — 直接生成常量到临时寄存器（wzr/xzr 对于 0）
  2. 已分配寄存器 — 直接返回物理寄存器名，标记为已使用
  3. 栈槽 — 分配临时寄存器，发射 ldr 指令

全局变量地址

loadAddr 对全局变量生成 ADRP+ADD 指令对：

// emitGlobalAddr:
//   adrp x10, global_var
//   add x10, x10, :lo12:global_var

Store 函数族

void storeInt(Value *v, const std::string &reg);
void storeFloat(Value *v, const std::string &reg);
void storeAddr(Value *v, const std::string &reg);
void storeVector(Value *v, const std::string &reg);

若值已分配物理寄存器，store 退化为 mov（或 fmov）。否则发射 str 到栈槽。

常量加载

整数常量（emitIntConst）

// 使用 movz + movk 两步加载 32 位整数：
//   movz wN, #LOW16        // 低 16 位
//   movk wN, #HIGH16, lsl #16  // 高 16 位（仅非零时）

浮点常量（emitFloatConst）

// 1. 将 IEEE 754 位表示加载到整数临时寄存器
//   movz w10, #LOW16
//   movk w10, #HIGH16, lsl #16
// 2. 通过 fmov 传输到浮点寄存器
//   fmov sN, w10

向量 Load/Store

loadVector

对常量向量逐 lane 构造；对栈槽中的向量使用 ldr qN（128 位加载）：

// 常量向量：
//   mov v0.s[0], w10
//   mov v0.s[1], w11
//   mov v0.s[2], w12
//   mov v0.s[3], w13

// 栈槽加载（正偏移，16 字节对齐）：
//   ldr q0, [x29, #OFFSET]

// 负偏移（ldr qN 不支持负偏移）：
//   sub x16, x29, #ABS_OFFSET
//   ldr q0, [x16]

示例

// IR:  %r = add i32 %a, %b
// 假设 %a 在栈槽 -8, %b 已分配 w3, %r 未分配寄存器

// loadInt(%a):
//   ldr w10, [x29, #-8]     // 从栈槽加载到临时寄存器
// loadInt(%b):
//   w3                       // 直接返回已分配寄存器

// add:
//   add w11, w10, w3         // 结果到另一个临时寄存器

// storeInt(%r, w11):
//   str w11, [x29, #-16]     // 写回 %r 的栈槽
