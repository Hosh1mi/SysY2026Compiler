IR 生成（GenIR）

GenIR 继承自 Visitor 接口，遍历 AST 并逐节点发射 IR 指令。 头文件 src/include/mid/ir/irGen.hpp，实现 src/mid/ir/irGen.cpp。

类结构

GenIR 实现 Visitor 接口的 23 个 visit 方法， 每个方法对应一种 AST 节点类型。核心成员： 

class GenIR: public Visitor {
public:
    IRStmtBuilder *builder;              // 指令构建器（维护插入点）
    Scope scope;                         // 作用域符号表
    std::unique_ptr<Module> module;      // IR 顶层模块

    // 23 个 visit 方法覆盖全部 AST 节点
    void visit(CompUnitAST &ast) override;
    void visit(DeclDefAST &ast) override;
    void visit(DeclAST &ast) override;
    void visit(DefAST &ast) override;
    void visit(InitValAST &ast) override;
    void visit(FuncDefAST &ast) override;
    void visit(FuncFParamAST &ast) override;
    void visit(BlockAST &ast) override;
    void visit(BlockItemAST &ast) override;
    void visit(StmtAST &ast) override;
    void visit(ReturnStmtAST &ast) override;
    void visit(SelectStmtAST &ast) override;
    void visit(IterationStmtAST &ast) override;
    void visit(AddExpAST &ast) override;
    void visit(LValAST &ast) override;
    void visit(MulExpAST &ast) override;
    void visit(UnaryExpAST &ast) override;
    void visit(PrimaryExpAST &ast) override;
    void visit(CallAST &ast) override;
    void visit(NumberAST &ast) override;
    void visit(RelExpAST &ast) override;
    void visit(EqExpAST &ast) override;
    void visit(LAndExpAST &ast) override;
    void visit(LOrExpAST &ast) override;
};

全局状态变量

IR 生成过程依赖一组文件级全局变量在各 visit 方法之间传递上下文：

变量类型作用
recentValValue*最近一次表达式的计算结果，所有 visit 方法通过它传递值
curTypeType*当前声明的类型（INT32_T / FLOAT_T）
isConstbool当前声明是否为 const
useConstbool是否处于常量折叠模式（全局初始值/数组维度）
currentFunctionFunction*当前正在生成的函数
retAllocaValue*函数返回值的 alloca 地址
retBBBasicBlock*函数统一返回块
whileCondBBBasicBlock*当前 while 的条件块（continue 跳转目标）
whileFalseBBBasicBlock*当前 while 的退出块（break 跳转目标）
trueBB / falseBBBasicBlock*if/while 的真/假分支目标块
has_brbool当前 BB 是否已发射终止指令（br/ret），后续指令跳过
requireLValboolLVal 是否需要返回地址（赋值左值）而非加载值

Scope 符号表

Scope 类实现词法作用域，用 vector<map<string, Value*>> 栈结构。 进入块时 enter() 压入空 map，退出时 exit() 弹出。 查找时从栈顶向栈底遍历，实现变量遮蔽。 

class Scope {
public:
    void enter() { symbol.push_back({}); }
    void exit()  { symbol.pop_back(); }
    bool in_global() { return symbol.size() == 1; }

    // 返回 true 表示成功，false 表示名字已存在
    bool push(std::string name, Value *val);

    // 从内向外查找，找不到返回 nullptr
    Value* find(std::string name);

private:
    std::vector<std::map<std::string, Value *>> symbol;
};

in_global() 判断当前是否在全局作用域（仅一层 map），决定变量声明走 GlobalVariable 路径还是 AllocaInst 路径。

变量声明（DefAST）

visit(DefAST) 根据 scope.in_global() 分流到全局或局部路径：

全局变量

全局标量通过 GlobalVariable 创建，初始值为编译期常量。 全局 const 若为单值，直接存入符号表而不创建 GlobalVariable。 

// 无初始化全局变量 → 默认初始化为 0
GlobalVariable* var = new GlobalVariable(varName, module.get(), curType, false, CONST_INT(0));
scope.push(varName, var);

// 全局 const 单值 → 直接存符号表
if (isConst) scope.push(varName, recentVal);

全局数组

全局数组使用 globalInit() 递归构建 ConstantArray 嵌套结构。 大括号嵌套的对齐由 mergeElements() 和 finalMerge() 处理， 不足部分以 ConstantZero 填充。

局部变量

局部标量通过 builder->create_alloca() 在当前 BB 中分配栈空间， 常量直接存入符号表不分配 alloca。 

// 局部变量
AllocaInst *varAlloca = builder->create_alloca(curType);
varAlloca->name_ = varName;
scope.push(varName, varAlloca);
builder->create_store(recentVal, varAlloca);  // 有初始化时 store

// 局部 const → 不分配 alloca
scope.push(varName, recentVal);

局部数组

局部数组通过 create_alloca(arrayTy) 分配，然后逐元素清零。 对于元素数超过 256 的大数组，生成 IR 循环清零以避免百万级指令导致编译超时： 

// 大数组（elemCnt > 256）：生成循环清零
if (elemCnt > 256) {
    auto idxAlloca = builder->create_alloca(INT32_T);
    builder->create_store(CONST_INT(0), idxAlloca);
    builder->create_br(zeroCondBB);
    // zeroCondBB: idx < elemCnt ? → zeroBodyBB / zeroEndBB
    // zeroBodyBB: i32P[idx] = 0; idx++; br zeroCondBB
    // zeroEndBB: 继续后续初始化
} else {
    // 小数组：展开为逐元素 store
    for (int i = 0; i < elemCnt; i++) {
        auto gep = builder->create_gep(i32P, {CONST_INT(i)});
        builder->create_store(CONST_INT(0), gep);
    }
}

初始化赋值通过 localInit() 递归处理嵌套大括号结构， 按 dimensionsCnt（各维度累计元素数）对齐写入。

函数定义（FuncDefAST）

函数定义生成统一的四段结构：entry 块 → 函数体 → retBB（统一返回）。 

void GenIR::visit(FuncDefAST &ast) {
    // 1. 收集参数类型和名称
    for (auto &funcFParam : ast.funcFParamList) funcFParam->accept(*this);
    auto funTy = new FunctionType(retType, params);
    auto func = new Function(funTy, *ast.id, module.get());
    scope.push(*ast.id, func);  // 在进入新作用域之前注册
    scope.enter();

    // 2. 创建 entry 块，先 alloca 所有参数，再 store
    auto bb = new BasicBlock(module.get(), "label_entry", func);
    builder->BB_ = bb;
    for (int i = 0; i < paramNames.size(); i++) {
        auto alloc = builder->create_alloca(params[i]);
        scope.push(paramNames[i], alloc);
    }
    for (int i = 0; i < paramNames.size(); i++) {
        builder->create_store(args[i], scope.find(paramNames[i]));
    }

    // 3. 创建统一返回块 retBB
    retBB = new BasicBlock(module.get(), "label_ret", func);
    retAlloca = builder->create_alloca(retType);  // 返回值存储
    // retBB 中的指令：load retAlloca → ret

    // 4. 生成函数体
    builder->BB_ = bb;
    ast.block->accept(*this);
    if (!builder->BB_->get_terminator()) builder->create_br(retBB);
}

返回块优化

若 retBB 仅有一个前驱且该前驱无条件跳转到 retBB，则合并两个块： 将 retBB 的指令移入前驱块，消除冗余的 store → load 对。

控制流生成

if 语句（SelectStmt）

生成三分支结构：trueBB、falseBB（或 elseBB）、nextIf。

void GenIR::visit(SelectStmtAST &ast) {
    trueBB  = new BasicBlock(..., "label_if_then_");
    falseBB = new BasicBlock(..., "label_if_else_");
    nextIf  = ast.elseStmt ? new BasicBlock(..., "label_if_end_") : falseBB;

    ast.cond->accept(*this);
    // 非 i1 类型需要与 0 比较
    if (recentVal->type_ == INT32_T)
        recentVal = builder->create_icmp_ne(recentVal, CONST_INT(0));
    builder->create_cond_br(recentVal, trueBB, falseBB);

    builder->BB_ = trueBB;
    ast.ifStmt->accept(*this);
    if (!builder->BB_->get_terminator()) builder->create_br(nextIf);

    if (ast.elseStmt) {
        builder->BB_ = falseBB;
        ast.elseStmt->accept(*this);
        if (!builder->BB_->get_terminator()) builder->create_br(nextIf);
    }
    builder->BB_ = nextIf;
}

while 语句（IterationStmt）

生成三块循环结构：whileCondBB → trueBB（循环体）→ 回跳 whileCondBB / 退出 falseBB。

void GenIR::visit(IterationStmtAST &ast) {
    whileCondBB = new BasicBlock(..., "label_while_cond_");
    trueBB      = new BasicBlock(..., "label_while_body_");
    falseBB     = new BasicBlock(..., "label_while_end_");
    whileFalseBB = falseBB;  // break 跳转到此

    builder->create_br(whileCondBB);
    builder->BB_ = whileCondBB;
    ast.cond->accept(*this);
    builder->create_cond_br(cond, trueBB, falseBB);

    builder->BB_ = trueBB;
    ast.stmt->accept(*this);
    if (!builder->BB_->get_terminator()) builder->create_br(whileCondBB);

    builder->BB_ = falseBB;  // 继续循环后续代码
}

break 发射 br whileFalseBB，continue 发射 br whileCondBB。 嵌套循环通过保存/恢复 whileCondBB、whileFalseBB、trueBB、falseBB 实现。

表达式生成

常量折叠

当 useConst 为 true 时（全局初始值计算），二元运算直接在 C++ 层面完成， 不发射 IR 指令。结果存入 recentVal 作为 ConstantInt 或 ConstantFloat。

类型自动转换

checkCalType(Value*[]) 处理混合类型运算：i1 零扩展为 i32， i32 与 float 混合时 i32 转为 float（create_sitofp）。

LVal 左值/右值

visit(LValAST) 根据 requireLVal 标志决定行为：

场景行为
赋值左侧requireLVal = true，返回指针（create_gep）
读取右值发射 create_load
传数组参数返回首地址指针（create_gep(ptr, {0, 0})）
局部常量直接返回 Value，不发射 load
全局常量数组在 ConstantArray 上逐层下标查找

短路求值

逻辑与（&&）和逻辑或（||）通过条件分支实现短路： 

// LAndExp: a && b
// 求值 a → icmp_ne a, 0 → cond_br(trueBB, falseBB)
// trueBB: 求值 b（只有 a 为真时才执行）
void GenIR::visit(LAndExpAST &ast) {
    auto tempTrue = trueBB;
    trueBB = new BasicBlock(..., "label_and_");
    ast.lAndExp->accept(*this);
    builder->create_cond_br(recentVal, trueBB, falseBB);
    builder->BB_ = trueBB;
    trueBB = tempTrue;  // 还原
    ast.eqExp->accept(*this);
}

// LOrExp: a || b（结构对称，跳到 falseBB 继续求值）

函数调用

visit(CallAST) 将 C 宏名 starttime/stoptime 映射为 _sysy_starttime/_sysy_stoptime，并在无实参时自动注入行号参数。 实参与形参类型不匹配时插入 sitofp/fptosi 转换。

返回语句（ReturnStmt）

所有 return 语句统一跳转到 retBB。返回值先 store 到 retAlloca， retBB 中再 load 并 ret。这样函数始终只有一个出口，简化后续优化。 

void GenIR::visit(ReturnStmtAST &ast) {
    if (ast.exp == nullptr) {
        builder->create_br(retBB);  // void return
    } else {
        ast.exp->accept(*this);
        // 类型转换后 store 到 retAlloca
        builder->create_store(recentVal, retAlloca);
        builder->create_br(retBB);
    }
    has_br = true;  // 标记当前 BB 已有终止指令
}
