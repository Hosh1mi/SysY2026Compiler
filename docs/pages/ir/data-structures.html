数据结构

IR 采用 LLVM 风格的四层容器结构，所有实体均继承自 Value 基类并维护 Use-Def 链。头文件位于 src/include/mid/ir/。

Type 类型系统

Type 是所有 IR 类型的基类，通过 TypeID 枚举区分类型种类。 复合类型（Array/Vector/Pointer/Function）持有对元素类型的引用。 

class Type {
public:
    enum TypeID {
        VoidTyID,      // void
        LabelTyID,     // 基本块标签
        IntegerTyID,   // 整数（i1 / i32）
        FloatTyID,     // 浮点（float32）
        FunctionTyID,  // 函数类型
        ArrayTyID,     // 数组类型
        VectorTyID,    // 向量（<4 x i32> / <4 x float>）
        PointerTyID,   // 指针类型
    };
    TypeID tid_;
    virtual std::string print();
};

类关键字段示例
IntegerTypenum_bits_i1（num_bits=1）、i32（num_bits=32）
ArrayTypecontained_, num_elements_[2 x [3 x i32]]
VectorTypecontained_, num_elements_<4 x i32>
PointerTypecontained_[2 x [3 x i32]]*

Value 基类与 Use-Def 链

Value 是所有 IR 实体（常量、指令、基本块、函数、参数等）的基类。 每个 Value 维护一个 use_list_，记录"谁在哪个操作数位置引用了我"。 

struct Use {
    Value* val_;          // 使用者（某条指令）
    unsigned int arg_no_; // 该 Value 在指令中的操作数序号
};

class Value {
public:
    Type* type_;
    std::string name_;
    std::list<Use> use_list_;

    std::list<Use>::iterator add_use(Value* val, unsigned arg_no);
    void remove_use(Value* val);
    void replace_all_use_with(Value* new_val);
    virtual std::string print() = 0;
};

replace_all_use_with() 遍历 use_list_，将所有引用该 Value 的操作数替换为 new_val， 是优化 Pass 中最常用的 IR 修改原语之一。

Module 顶层容器

Module 是 IR 的最顶层容器，持有全局变量列表和函数列表，并预置五个基本类型单例。 复合类型（Pointer/Array/Vector）通过 map 缓存，避免重复创建。 

class Module {
public:
    // 基本类型单例（构造函数中创建）
    Type* void_ty_;          // void
    Type* label_ty_;         // label（基本块类型）
    IntegerType* int1_ty_;   // i1
    IntegerType* int32_ty_;  // i32
    Type* float32_ty_;       // float

    std::vector<GlobalVariable*> global_list_;
    std::vector<Function*> function_list_;

    // 类型缓存（避免重复创建）
    PointerType*  get_pointer_type(Type* contained);
    ArrayType*    get_array_type(Type* contained, unsigned num_elements);
    VectorType*   get_vector_type(Type* contained, unsigned num_elements);

    void verify();  // IR 完整性校验
};

Function 与 Argument

Function 继承自 Value，持有基本块列表和参数列表。 构造函数根据 FunctionType 自动创建 Argument 对象。 无基本块的函数视为声明（is_declaration() 返回 true）。 

class Argument : public Value {
    Function* parent_;
    unsigned arg_no_;  // 参数序号
};

class Function : public Value {
    std::vector<BasicBlock*> basic_blocks_;
    std::vector<Argument*>   arguments_;
    Module* parent_;
    unsigned seq_cnt_;   // 命名序号计数器
    unsigned gep_cnt_;   // GEP 独立命名计数器
    int use_ret_cnt;     // 返回值的实际使用次数

    bool is_declaration();      // 无基本块 → 仅为声明
    Type* get_return_type();
    BasicBlock* getRetBB();     // 获取唯一 return 基本块
    void set_instr_name();      // 统一命名所有未命名指令
};

DominatorInfo 支配树

由 Function 惰性计算并缓存，CFG 变更时自动失效。各优化 Pass 通过 getDominatorInfo() 复用。 

struct DominatorInfo {
    bool valid = false;
    std::map<BasicBlock*, BasicBlock*>             idom;        // 立即支配者
    std::map<BasicBlock*, std::set<BasicBlock*>>   domFront;    // 支配边界
    std::map<BasicBlock*, std::vector<BasicBlock*>> domChildren; // 支配树子节点
    bool dominates(BasicBlock *a, BasicBlock *b) const;
};

BasicBlock 基本块

BasicBlock 继承自 Value（类型为 label），包含一条指令链表以及 CFG 前驱/后继关系。 指令链表使用 std::list 以支持高效的插入和删除操作。 

class BasicBlock : public Value {
    std::list<Instruction*> instr_list_;  // 指令链表
    Function* parent_;

    // CFG 信息
    std::vector<BasicBlock*> pre_bbs_;    // 前驱块
    std::vector<BasicBlock*> succ_bbs_;   // 后继块

    // 支配树信息
    BasicBlock* idom_;                     // 立即支配者
    std::set<BasicBlock*> dom_frontier_;   // 支配边界
    std::set<BasicBlock*> rdom_frontier_;  // 后支配边界
    std::set<BasicBlock*> rdoms_;          // 后支配集合

    // 活跃变量分析
    std::set<Value*> live_in;
    std::set<Value*> live_out;
};

指令插入方法

方法说明
add_instruction()在末尾追加
add_instruction_front()在开头插入
add_instruction_before_terminator()在终止指令（br/ret）之前插入
add_instruction_before_inst()在指定指令之前插入
get_terminator()获取末尾终止指令
delete_instr()删除指令并清除 use 关系
remove_instr()移出指令但保留 use 关系（用于跨 BB 移动）

Instruction 指令

Instruction 继承自 Value，是所有 IR 指令的基类。 操作数通过 set_operand() 设置，自动维护 Use-Def 链。

OpID 操作码枚举

enum OpID {
    Ret = 11, Br,                           // 终止指令
    FNeg,                                   // 浮点取负
    Add, Sub, Mul, SDiv, SRem, UDiv, URem,  // 整数二元运算
    FAdd, FSub, FMul, FDiv,                 // 浮点二元运算
    Shl, LShr, AShr, And, Or, Xor,           // 位运算
    Alloca, Load, Store,                     // 内存操作
    Select,                                  // select i1 cond, T val1, F val2
    GetElementPtr,                           // 地址计算
    ZExt, FPtoSI, SItoFP, BitCast, Clz,       // 类型转换 + 内建
    InsertElement,                            // 向量元素插入
    ICmp, FCmp, PHI, Call                    // 比较、phi、调用
};

操作数管理

class Instruction : public Value {
    OpID op_id_;
    unsigned num_ops_;
    std::vector<Value*> operands_;                         // 操作数列表
    std::vector<std::list<Use>::iterator> use_pos_;        // 对应 use_list 迭代器
    BasicBlock* parent_;

    void set_operand(unsigned i, Value* v);  // 设置操作数，自动维护 use-def
    void add_operand(Value* v);              // 追加操作数（phi 动态增加入边）
    void remove_operands(int i1, int i2);    // 删除指定范围操作数
};

use_pos_ 与 operands_ 一一对应，存储该指令在各操作数的 use_list_ 中的迭代器位置， 使得删除或替换操作数时可以 O(1) 直接 erase，无需遍历。

大多数指令子类提供一个额外的 (..., bool flag) 构造函数，创建指令但不自动插入到 BasicBlock。 调用方需手动通过 add_instruction_before_inst() 等方法插入，常用于跨 BB 移动或精确控制插入位置。

Constant 常量

Constant 继承自 Value，表示编译期已知的值，无名（name == ""）。

类字段示例
ConstantIntint value_i32 42
ConstantFloatfloat value_0x4057C21FC0000000
ConstantArrayvector<Constant*> const_array[3 x i32] [i32 42, i32 11, i32 74]

ConstantZero无zeroinitializer

GlobalVariable 全局变量

class GlobalVariable : public Value {
    bool is_const_;       // 是否为常量（constant vs global）
    Constant* init_val_;  // 初始值（可为 nullptr）
};

对应 IR 中的 @a = global [4 x i32] [...] 或 @c = constant [5 x i32] [...]。 Value 的 type_ 为指针类型（PointerType），指向实际存储类型。

IRStmtBuilder 构建器

IRStmtBuilder 是工厂类，维护当前插入点（BB_）和模块引用（m_）， 提供 create_* 系列方法在当前基本块中创建各类指令。 

class IRStmtBuilder {
    BasicBlock* BB_;
    Module* m_;

    BinaryInst* create_iadd(Value* v1, Value* v2);
    ICmpInst*   create_icmp_eq(Value* v1, Value* v2);
    BinaryInst* create_fadd(Value* v1, Value* v2);
    CallInst*   create_call(Value* func, std::vector<Value*> args);
    BranchInst* create_cond_br(Value* cond, BasicBlock* t, BasicBlock* f);
    ReturnInst* create_ret(Value* val);
    AllocaInst* create_alloca(Type* ty);
    StoreInst*  create_store(Value* val, Value* ptr);
    LoadInst*   create_load(Value* ptr);
    GetElementPtrInst* create_gep(Value* ptr, std::vector<Value*> idxs);
    ZextInst*   create_zext(Value* val, Type* ty);
    // ... 更多 create_* 方法
};
