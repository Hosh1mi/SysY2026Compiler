循环分析（LoopInfo）

LoopInfo 对单个函数进行分析：检测自然循环、构建嵌套树、 识别关键控制流块、以及规范归纳变量（canonical IV）。 头文件 src/include/mid/analysis/loopInfo.hpp。

Loop 结构

class Loop {
public:
    BasicBlock *header    = nullptr;   // 循环入口，被所有 latch 跳回
    BasicBlock *preheader = nullptr;   // header 的唯一外部前驱
    std::vector<BasicBlock *> latches; // 回边来源（跳回 header 的块）
    std::vector<BasicBlock *> exiting; // 循环内、有后继落在循环外的块
    std::vector<BasicBlock *> exits;   // 循环外的后继块
    std::set<BasicBlock *>    blocks;  // 本循环所有块

    Loop *parent = nullptr;           // 外层循环
    std::vector<Loop *> children;     // 内层循环
    int depth = 0;                     // 顶层=0

    PhiInst *canonicalIV = nullptr;    // 规范归纳变量 phi
    Value   *tripCount   = nullptr;    // 循环上界 N
};

例子：while 循环

// SysY 源码
int sum = 0;
int i = 0;
while (i < 10) {
    sum = sum + i;
    i = i + 1;
}

对应的 IR CFG 和 LoopInfo 分析结果：

entry:
  %sum = alloca i32
  store i32 0, %sum
  %i = alloca i32
  store i32 0, %i
  br label_while_cond         ← preheader

label_while_cond:            ← header
  %i.load = load %i
  %cond = icmp slt %i.load, 10
  br %cond, label_body, label_exit

label_body:                  ← latch (也是 body)
  %sum.load = load %sum
  %i.load2 = load %i
  %sum.next = add %sum.load, %i.load2
  store %sum.next, %sum
  %i.next = add %i.load2, 1
  store %i.next, %i
  br label_while_cond        ← 回边

label_exit:                  ← exit
字段值
headerlabel_while_cond
preheaderentry
latches[label_body]
exiting[label_while_cond]（cond_br 跳到循环外）
exits[label_exit]
canonicalIVnull（因为 i 通过 store/load 维护，Mem2Reg 后才是 phi）

例子：Mem2Reg 后的规范循环

// Mem2Reg 提升后
entry:
  br label_while_cond

label_while_cond:
  %i1 = phi i32 [0, entry], [%i2, label_body]
  %sum1 = phi i32 [0, entry], [%sum2, label_body]
  %cond = icmp slt %i1, 10
  br %cond, label_body, label_exit

label_body:
  %sum2 = add %sum1, %i1
  %i2 = add %i1, 1
  br label_while_cond

label_exit:
  call putint(%sum1)

此时 LoopInfo 可识别规范归纳变量：

字段值
canonicalIV%i1（phi init=0, step=add i1 1）
tripCount10（icmp_slt 的上界）
predicateICMP_SLT

嵌套循环

// SysY 源码
for (int i = 0; i < N; i++) {
    for (int j = 0; j < M; j++) {
        a[i][j] = 0;
    }
}

LoopInfo 构建的嵌套树：

Loop@i_header (depth=0)
  └── Loop@j_header (depth=1)
        header: j_header
        preheader: i_body  (外层循环体块，同时是内层的 preheader)
        canonicalIV: %j1 = phi [0, preheader], [j+1, j_latch]
        tripCount: M

分析流水线

void LoopInfo::analyze(Function *func) {
    reset();
    auto rpo = computeRPO(func);           // 1. 逆后序
    computeDominators(rpo);                 // 2. 支配树 (Cooper-Harvey-Kennedy)
    findLoops(func);                        // 3. 回边检测 → 自然循环
    for (auto &loop : loops_) enrichLoop(loop.get()); // 4. preheader/latches/exits
    buildNestTree();                        // 5. 嵌套树 (按 blocks 数排序)
    for (auto &loop : loops_) analyzeIV(loop.get());  // 6. 规范 IV 识别
}
