分析模块总览

分析模块为优化 Pass 提供只读的查询接口，不修改 IR。 所有分析通过 AnalysisManager 统一管理，支持惰性计算与缓存失效。

AnalysisManager

AnalysisManager 是分析的统一入口，按需计算、缓存结果， 并在 Pass 修改 IR 后根据 PreservedAnalyses 位掩码自动失效过期缓存。 

class AnalysisManager {
public:
    BasicAliasAnalysis &getBasicAA(Module *module);
    LoopInfo           &getLoopInfo(Function *func);
    ScalarEvolution    &getScalarEvolution(Function *func);

    void invalidate(Module *module, const PreservedAnalyses &pa);
    void invalidateFunction(Function *func, const PreservedAnalyses &pa);
    void clear(Function *func);
    void clear();
};

使用示例

// 在某个 Pass 的 execute() 中
void MyPass::execute(Module *module) {
    for (auto func : module->function_list_) {
        if (func->is_declaration()) continue;

        // 按需获取 LoopInfo（首次调用时自动计算）
        LoopInfo &LI = AM.getLoopInfo(func);
        for (auto loop : LI.topLevelLoops()) {
            // 使用循环信息...
        }

        // 按需获取 ScalarEvolution（依赖 LoopInfo）
        ScalarEvolution &SE = AM.getScalarEvolution(func);
        // ...
    }
}

缓存与失效

// Pass 修改了 CFG → 声明不保留 LoopInfo
PreservedAnalyses pa = PreservedAnalyses::none();
// pa 默认不保留任何分析，AM 会清空缓存

// Pass 只做局部变换，不改变循环结构
PreservedAnalyses pa = PreservedAnalyses::none();
pa.preserveLoopInfo();   // 保留 LoopInfo
pa.preserveSCEV();       // 保留 SCEV
// AM 只失效 BasicAA，LoopInfo/SCEV 缓存保留

PreservedAnalyses 位掩码

class PreservedAnalyses {
    bool all_ = false;
    std::uint32_t mask_ = 0;

    enum AnalysisBit : std::uint32_t {
        BasicAA  = 1u << 0,
        LoopInfo = 1u << 1,
        SCEV     = 1u << 2,
    };

    void preserveBasicAA()   { mask_ |= BasicAA; }
    void preserveLoopInfo()  { mask_ |= LoopInfo; }
    void preserveSCEV()      { mask_ |= SCEV; }
};
