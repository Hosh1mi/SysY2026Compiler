标量演化（ScalarEvolution）

ScalarEvolution 将 IR 中的 Value 表达为关于循环归纳变量的符号化表达式（SCEV）， 用于计算循环迭代次数、数组访问的 stride、以及判断循环不变量。 头文件 src/include/mid/analysis/scalarEvolution.hpp。

SCEV 表达式类型

类型示例说明
SCEVConstant42编译期常量
SCEVUnknown%n无法简化的运行时值
SCEVAddExpr%n + 3加法组合
SCEVMulExpr4 * %n乘法组合
SCEVAddRecExpr{0, +, 1}<L>循环递推：初始值=0，步长=+1，属于循环 L
SCEVCouldNotCompute—无法计算

例子：简单循环

// IR (Mem2Reg 后)
label_while_cond:
  %i = phi i32 [0, entry], [%i.next, body]
  %sum = phi i32 [0, entry], [%sum.next, body]
  %cond = icmp slt %i, 10
  br %cond, body, exit

body:
  %sum.next = add %sum, %i
  %i.next = add %i, 1
  br label_while_cond

SCEV 分析结果：

ValueSCEV解释
%i{0, +, 1}<L>AddRec：初始 0，每次 +1
%sum{0, +, {0, +, 1}<L>}<L>AddRec：初始 0，步长是 %i 本身（二次递推）
%i.next{1, +, 1}<L>等价于 %i + 1
1010常量

例子：循环迭代次数

// 查询循环的迭代次数
ScalarEvolution &SE = AM.getScalarEvolution(func);
const SCEV *tc = SE.getTripCount(loop);
// 对于 while (i < 10; i += 1)，tc = SCEVConstant(10)

getTripCount() 要求循环有规范 IV（init=0, step=+1）， 且 header 终止指令为 icmp_slt iv, bound，此时返回 bound 的 SCEV。

例子：GEP 线性化

// IR: 二维数组访问
%gep = getelementptr [10 x [20 x i32]], [10 x [20 x i32]]* %a, i32 0, i32 %i, i32 %j

getLinearizedGEP() 将多维索引线性化为一维偏移：

SCEVGEPInfo info = SE.getLinearizedGEP(gep);
// info.shape = [10, 20]  (数组维度)
// info.elementOffset = %i * 20 + %j  (元素偏移)
// info.elementType = i32

这对于判断数组访问是否连续（stride=1）、以及依赖分析中计算方向向量至关重要。

常用查询接口

class ScalarEvolution {
    // 获取 Value 的 SCEV 表达式
    const SCEV *getSCEV(Value *v);

    // 获取循环迭代次数
    const SCEV *getTripCount(Loop *loop);

    // GEP 线性化
    SCEVGEPInfo getLinearizedGEP(GetElementPtrInst *gep);

    // 判断 SCEV 是否为循环不变量
    bool isLoopInvariant(const SCEV *s, Loop *loop) const;

    // 提取 AddRec 中属于指定循环的部分
    const SCEVAddRecExpr *getAddRecForLoop(const SCEV *s, Loop *loop) const;
};
