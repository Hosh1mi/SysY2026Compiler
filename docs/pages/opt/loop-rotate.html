LoopRotate

循环旋转 Pass，将循环条件从顶部移到底部，消除 header 块的额外跳转开销。

概览

LoopRotate 将经典的“先判断后执行”循环转换为“先执行后判断”的形式。具体做法是将 header 块的指令分别克隆到 preheader（首次迭代前）和 latch（后续迭代前），然后将条件分支下移到 latch，从而消除 header 块。

变换过程

rotateLoop

  1. preheader 克隆：将 header 中的非 phi 指令克隆到 preheader（首次迭代前的执行）
  2. latch 克隆：将 header 中的非 phi 指令克隆到 latch 的回边跳转前（后续迭代前的执行）
  3. 条件分支下移：header 的条件分支移动到 latch，直接控制是否继续循环
  4. header 块消除：原 header 块被绕过，循环不再有独立的 header
旋转前
header:
  %iv = phi [0, pre], [%iv.next, latch]
  %cond = icmp slt %iv, %N
  br %cond, body, exit

body:
  ... // 循环体
  br latch

latch:
  %iv.next = add %iv, 1
  br header
旋转后
preheader:
  %iv_0 = 0
  %cond_0 = icmp slt %iv_0, %N
  br %cond_0, body, exit    // 首次判断

body:
  ... // 循环体
  br latch

latch:
  %iv.next = add %iv_0_or_prev, 1
  %cond = icmp slt %iv.next, %N
  br %cond, body, exit      // 后续判断
