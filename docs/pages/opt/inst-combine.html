InstCombine

指令组合与代数简化 Pass，采用工作表驱动的 Visitor 架构，对每条指令尝试代数恒等式、常量折叠、强度削弱等局部变换，直到不动点。

架构

工作表驱动

所有指令初始入队，逐个弹出并由对应 Visitor 尝试简化。若替换发生：

  1. 原指令的使用者重新入队（新操作数可能触发进一步简化）
  2. 替换结果本身若是指令也入队
  3. 原指令的操作数尝试下沉（trySinkInstruction），若下沉成功也入队

终止指令（br/ret）不参与简化。

指令下沉

当指令替换导致某操作数仅剩一个使用者，且该使用者在不同基本块时，尝试将操作数下沉到使用者前面。安全性条件：使用者所在块必须以下沉指令所在块为唯一前驱（保证支配关系）。

仅对纯计算指令（add/sub/mul/div/rem/shift/and/or/xor/zext/fneg 等）执行下沉，load/store/call 永不移动。

通用规则模式

大部分算术指令共享以下通用规则模式（以二元运算 op x, y 为例）：

#规则示例
1常量折叠：op C1, C2 → C3add 3, 5 → 8
2常量右移：op C, x → op x, Cadd 5, %x → add %x, 5
3单位元：op x, identity → xadd %x, 0 → %x
4再结合：op (op x, C1), C2 → op x, op(C1,C2)add (add %x,3), 5 → add %x, 8

加减法 (Add/Sub)

visitAdd 规则

#规则示例
1–4通用规则（见上表）
5移位融合：x + (x << k) → mul x, 2k+1add %x, (shl %x, 2) → mul %x, 5
6加法转 OR：add x, C → or x, C（当 x & C == 0）add (shl %x,8), 3 → or (shl %x,8), 3

visitSub 规则

#规则示例
1–2常量折叠 + 单位元 x-0
3自消：x - x → 0
4再结合：(add x, C1) - C2 → add x, C1-C2sub (add %x,10), 3 → add %x, 7
5再结合：(sub x, C1) - C2 → sub x, C1+C2sub (sub %x,3), 5 → sub %x, 8
6移位融合：(x << k) - x → mul x, 2k-1sub (shl %x,3), %x → mul %x, 7

浮点加减法

visitFAdd/visitFSub/visitFNeg 支持类似的常量折叠、单位元和自消规则，并包含浮点特有变换：

Visitor规则示例
visitFAddfneg(x) + fneg(y) → fneg(x+y)
visitFSubfsub x, fneg(y) → fadd x, y
visitFSubfsub 0.0, x → fneg x
visitFNegfneg(fneg(x)) → x
visitFNegfneg(fsub(x,y)) → fsub(y,x)

示例：移位融合

优化前
  %t1 = shl i32 %x, 3    ; x * 8
  %t2 = add i32 %x, %t1  ; x + 8x = 9x
优化后
  %t2 = mul i32 %x, 9    ; 后端可发射 add w0,w0,w0,lsl #3

乘除法 (Mul/Div/Rem)

visitMul 规则

#规则示例
1–5常量折叠 + 右移 + 单位元 x*1 + 零元 x*0 + 再结合
6加减融合：当 mul x, 2k 的唯一使用者是 add/sub 且涉及同一 x，融合为 mul x, 2k±1
7强度削弱：mul x, 2k → shl x, kmul %x, 8 → shl %x, 3

visitSDiv 规则

#规则示例
1常量折叠（除零保护）
2单位元：x / 1 → x
3零被除数：0 / x → 0
4x / -1 → sub 0, x（取负）
5强度削弱：sdiv x, 2k → ashr x, k（当 x≥0 或 x 是 2k 的倍数）sdiv %x, 4 → ashr %x, 2
6变量除数证明为 2k：sdiv x, pow2_var → ashr x, k
7变量除数证明为 2 的幂（k 未知）：sdiv x, pow2 → ashr x, (31 - clz(y))

visitSRem 规则

#规则示例
1–3常量折叠 + x%1→0 + 0%x→0
4a取模转位运算：srem x, 2k → and x, 2k-1（当唯一使用者是 icmp eq/ne 0）
4bsrem x, 2k → and x, 2k-1（当 x≥0 或 x 是 2k 的倍数）srem %x, 8 → and %x, 7

浮点乘除

visitFMul/visitFDiv 支持常量折叠、单位元（x*1.0, x/1.0）、零元（x*0.0→0.0）和零被除数（0.0/x→0.0）。

示例：乘法强度削弱

优化前
  %t = mul i32 %x, 16
优化后
  %t = shl i32 %x, 4

示例：乘法加减融合

优化前
  %t1 = mul i32 %x, 4   ; x * 4
  %t2 = add i32 %x, %t1  ; x + 4x = 5x
优化后
  %t2 = mul i32 %x, 5    ; 融合为单条乘法

移位 (Shl/LShr/AShr)

三种移位指令共享相同的规则结构：

#规则说明
1常量折叠注意 overshift：C >= bitwidth 时 shl/lshr 结果为 0，ashr 填充符号位
3单位元：x shift 0 → x
4超移位：x shift C (C ≥ bitwidth)shl/lshr → 0；ashr → x >> (bits-1)
5冗余移位：(x shift C1) shift C2 → x shift (C1+C2)仅当 C1+C2 < bitwidth 时安全

注意：移位不可交换，不做常量右移规范化。

示例：冗余移位合并

优化前
  %t1 = shl i32 %x, 2
  %t2 = shl i32 %t1, 3
优化后
  %t2 = shl i32 %x, 5

位运算 (And/Or/Xor)

#AndOrXor
1常量折叠
2常量右移
3x & -1 → xx | 0 → xx ^ 0 → x
4x & 0 → 0x | -1 → -1x ^ x → 0
5x & x → xx | x → x
6再结合：(x op C1) op C2 → x op (C1 op C2)

示例：位运算再结合

优化前
  %t1 = and i32 %x, 255   ; 取低 8 位
  %t2 = and i32 %t1, 15   ; 再取低 4 位
优化后
  %t2 = and i32 %x, 15    ; 255 & 15 = 15

比较与选择 (ICmp/Select)

visitICmp 规则

#规则示例
1常量折叠：icmp pred C1, C2 → true/falseicmp sgt 5, 3 → 1
2常量右移 + 谓词交换：icmp pred C, x → icmp swapped_pred x, Cicmp sgt 10, %x → icmp slt %x, 10
3自比较：x == x → 1, x < x → 0 等
4加减折叠：foldICmpAddSub（见下文）

foldICmpAddSub — 比较中的加减消除

两类模式：

类别规则示例
A: 谓词调整icmp sle (add x, 1), y → icmp slt x, yicmp sle (add %x,1), %y → icmp slt %x, %y
A: 谓词调整icmp sgt (sub x, 1), y → icmp sge x, y
B: 常量折叠icmp eq (add x, C1), C2 → icmp eq x, C2-C1icmp eq (add %x,5), 10 → icmp eq %x, 5

visitSelect 规则

#规则示例
1常量条件：select 1, x, y → x
2双臂相同：select c, x, x → x
3布尔规范化：select c, 1, 0 → zext cselect %c, 1, 0 → zext %c

示例：谓词交换 + 常量右移

优化前
  %cmp = icmp sgt i32 10, %x  ; 常量在左边
优化后
  %cmp = icmp slt i32 %x, 10  ; 常量移到右边，谓词取反

示例：加减折叠

优化前
  %t = add i32 %x, 1
  %cmp = icmp sle i32 %t, %y   ; x+1 <= y
优化后
  %cmp = icmp slt i32 %x, %y   ; 等价于 x < y

辅助分析函数

以下辅助函数提供更丰富的值域信息，使规则能处理更复杂的场景：

函数功能使用者
isPowerOfTwo(v)判断整数是否为 2 的幂visitMul, visitSDiv, visitSRem
isKnownNonNegative(x)判断值是否非负（符号分析）visitSDiv, visitSRem
isKnownMultipleOf(x, k, bb)判断值是否为 2k 的倍数visitAdd, visitSDiv, visitSRem
isKnownPowerOfTwo(y, k)判断变量是否可证明为 2kvisitSDiv
isProvenPowerOfTwo(y)判断变量是否可证明为 2 的幂（k 未知）visitSDiv
getSwappedPredicate(op)交换比较谓词（SGT↔SLT, SGE↔SLE）visitICmp, foldICmpAddSub
