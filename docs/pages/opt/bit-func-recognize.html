BitFuncRecognize

通过位级抽象解释识别位运算模拟函数，将调用站点重写为等价的 IR 位运算指令。

概览

SysY 语言没有位运算符，某些运行时库函数（如 rotlN、rotrN）实质是位运算的循环模拟。本 Pass 对每个候选函数的 IR 体进行逐位抽象解释，跟踪每个 i32 SSA 值的 32 位符号表达式，并将返回值的位向量与闭式模式匹配，识别后直接用 AND/OR/XOR/SHL 等 IR 指令替换调用。

抽象域

BitExpr（符号表达式）

hash-consing 的 DAG 节点，操作码包括：

  • ZERO / ONE — 常量位
  • BIT_OF(source, idx) — 取 source 的第 idx 位
  • AND / OR / XOR / NOT — 位运算组合
  • ICMP_EQ_CONST — 物化的 icmp eq Value, const 谓词
  • TOP — 未知位

使用 BitExprArena（RAII 作用域 + thread_local）管理生命周期，保证同一表达式全局唯一（指针相等即语义相等）。

BitVec（32 位抽象值）

每个 i32 值用 32 个 BitExpr 指针表示，bv[0] 是最低位。智能构造函数自动简化（如 AND(x, ZERO) → ZERO）。

传输函数

IR 指令位级语义
常量每位映射为 ZERO 或 ONE
Copy / Bitcast直接复制 BitVec
AND / OR / XOR逐位对应操作
SHL (常量)左移 k 位，低位填 ZERO
LSHR (常量)右移 k 位，高位填 ZERO（仅用于内部分析）
Mul (常量 2k)等价于 SHL k
SDiv (常量 2k)等价于 LSHR k（符号扩展）
Add / Sub全加器进位跟踪（部分支持）
ICmp结果 i1 用 ICMP_EQ_CONST 物化
Select根据 i1 条件选择两个 BitVec
PhiFork-join merge，取 IPDOM 交汇点

闭式识别器

对返回值的 32 位 BitVec 进行模式匹配：

  • AND：bv[i] = AND(BIT_OF(X, i), BIT_OF(Y, i))
  • OR：bv[i] = OR(BIT_OF(X, i), BIT_OF(Y, i))
  • XOR：bv[i] = XOR(BIT_OF(X, i), BIT_OF(Y, i))
  • SHL（常量 k）：bv[i] = BIT_OF(X, i-k) for i≥k, else ZERO
  • VAR_SHL（变量移位）：参数化模式，检测 countdown 参数
  • VAR_LSHR（变量右移）：参数化模式，检测 countdown 参数

SCEV-lite 参数化回退

对于循环实现的变量移位（如 for(i=n; i>0; i--) x *= 2），当闭式匹配失败时，尝试识别 countdown 参数并构建参数化表达式。

调用站点重写

识别成功后，rewriteCallSites 将调用替换为对应的 IR 指令：

  • AND/OR/XOR/SHL：直接创建对应的 BinaryInst
  • VAR_SHL：创建 shl x, n（带范围检查确保 n ∈ [0, 31]）
  • VAR_LSHR：创建 lshr x, n（带范围检查）

安全限制

  • 参数数量限制 1..3（匹配已知模式）
  • 预算限制：MAX_VISITS=4000，超过则放弃分析
  • 常量 LSHR 不识别（与 sdiv 语义冲突）
  • 仅处理无副作用的纯函数
