LICM

循环不变代码外提 Pass，将循环内不变的计算提升到 preheader，减少重复计算。

概览

LICM（Loop Invariant Code Motion）识别循环体内不依赖循环变量的指令，将其提升到 preheader。同时消除单前驱块中的冗余 phi 节点和循环 header 中的 trivial phi。

循环检测

使用自实现的 findLoops：扫描回边（bb → succ 且 succ 支配 bb），然后反向遍历收集循环体。相同 header 的多条回边合并为同一个循环（避免不完整 body 导致 preheader 检测失败）。

不变性判定

isInvariant

一个值在循环中不变，当且仅当：

  • 它是常量、全局变量或函数参数
  • 它的定义不在循环体内
  • 它已在待提升集合 toHoist 中（传递性）

可选的 ScalarEvolution 辅助验证：如果 SCEV 分析判定为循环不变，则增强信心。

isSafeToHoist

  • phi / br / ret / store / alloca：不可提升
  • call：仅当 callee 是纯函数（BAA.isPure）时可提升
  • load：仅当循环内无任何指令 ModRef 该地址时可提升
  • 其他指令（二元运算、GEP 等）：可提升

提升过程

迭代式提升：每轮扫描循环体找出所有不变指令，移动到 preheader 的 terminator 前，直到无新指令可提升（处理传递性依赖）。

Phi 消除

eliminateSinglePredPhis

对函数中所有单前驱块，删除冗余 phi（直接替换为唯一 incoming 值）。

eliminateTrivialHeaderPhis

对循环 header 中的 phi，如果 latch 入边是自引用（phi 自身）、其他入边值相同且来自循环外，则删除 phi 替换为该常量值。

分析管理器集成

LICM 通过 AnalysisManager 获取 LoopInfo、ScalarEvolution、BasicAliasAnalysis，变换后通过 invalidateFunction 失效缓存（保留 BasicAA）。

示例

算术指令外提

以下循环中，%x * %y 和 %x + %y 不依赖循环变量，可提升到 preheader：

优化前
preheader:
  br label %header

header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %mul = mul i32 %x, %y          ; 循环不变，但每次迭代重复计算
  %add = add i32 %x, %y          ; 同上
  %gep = getelementptr i32, i32* %A, i32 %iv
  store i32 %mul, i32* %gep
  %cmp = icmp slt i32 %iv, %N
  br %cmp, label %latch, label %exit

latch:
  %iv.next = add i32 %iv, 1
  br label %header
优化后
preheader:
  %mul = mul i32 %x, %y          ; 提升到 preheader，只计算一次
  %add = add i32 %x, %y          ; 同上
  br label %header

header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %gep = getelementptr i32, i32* %A, i32 %iv
  store i32 %mul, i32* %gep
  %cmp = icmp slt i32 %iv, %N
  br %cmp, label %latch, label %exit

latch:
  %iv.next = add i32 %iv, 1
  br label %header

Load 外提（别名分析安全时）

如果循环内没有对该地址的 Mod/Ref，load 也可外提：

优化前
header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %v = load i32, i32* %p         ; 若循环内无任何指令修改 %p 指向的内存
  %r = add i32 %v, %iv
  ...
  br %cmp, label %latch, label %exit
优化后
preheader:
  %v = load i32, i32* %p         ; 提升到 preheader
  br label %header

header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %r = add i32 %v, %iv           ; %v 现在是循环外的值
  ...
  br %cmp, label %latch, label %exit

Trivial Phi 消除

当 header phi 的 latch 入边是自引用、其他入边值相同时，可消除该 phi：

优化前
header:
  %x = phi i32 [42, %preheader], [%x, %latch]   ; latch 入边是自引用
  ...                                            ; preheader 入边 = 42，唯一外部值
优化后
; %x 直接替换为常量 42，phi 节点删除
