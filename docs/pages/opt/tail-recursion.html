TailRecursionEliminate

尾递归消除 Pass，将尾递归调用转化为循环，通过参数 phi 和跳转回环实现迭代代替递归。

概览

TailRecursionEliminate 识别函数中的尾递归调用，将其转化为循环。支持两种尾调用模式，并允许部分转换（非尾调用的自调用保留不动）。

尾调用模式

模式IR 形态说明
模式 1ret (call @f ...)函数直接返回自调用结果
模式 2call @f ... → br ret_bb → phi → ret调用后无条件跳转到返回块，通过 phi 汇合后返回

变换流程

  1. 创建循环头块：在 entry 之后插入 label_tailrec_header
  2. 参数 phi：为每个函数参数在 header 中创建 phi，初始值来自 entry
  3. 融入 entry：将 entry 内容移入 header，entry 变为无条件跳转到 header 的 preheader
  4. 重写尾调用：将实参加入 phi，将调用+跳转替换为到 header 的跳转
  5. 清理 phi：对模式 2，移除返回块中已转换的 phi 输入边，单输入 phi 被消除

示例

优化前 — 阶乘递归
define i32 @factorial(i32 %n, i32 %acc) {
entry:
  %cmp = icmp sle i32 %n, 1
  br i1 %cmp, label %ret, label %recur

recur:
  %n1 = sub i32 %n, 1
  %a1 = mul i32 %acc, %n
  %r = call i32 @factorial(i32 %n1, i32 %a1)  ; 尾调用
  ret i32 %r

ret:
  ret i32 %acc
}
优化后 — 转化为循环
define i32 @factorial(i32 %n, i32 %acc) {
entry:
  br label %header

header:
  %n.phi = phi i32 [%n, %entry], [%n1, %recur]
  %a.phi = phi i32 [%acc, %entry], [%a1, %recur]
  %cmp = icmp sle i32 %n.phi, 1
  br i1 %cmp, label %ret, label %recur

recur:
  %n1 = sub i32 %n.phi, 1
  %a1 = mul i32 %a.phi, %n.phi
  br label %header      ; 循环回跳

ret:
  ret i32 %a.phi
}
