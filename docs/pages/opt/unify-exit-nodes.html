UnifyExitNodes

出口块统一 Pass，将多个返回块合并为单一返回块，通过 phi 节点汇合返回值。

概览

当函数有多个返回块时，创建一个统一的返回块 label_unified_ret，所有原返回块改为无条件跳转到该块。非 void 函数通过 phi 节点汇合各返回块的值。

变换步骤

  1. 收集所有以 ret 结尾的基本块
  2. 若只有 0 或 1 个返回块，跳过
  3. 创建统一返回块，插入 phi（非 void）或 void ret
  4. 将所有返回块的 ret 替换为 br + phi 参数填充

示例

优化前
define i32 @foo(i32 %c) {
  %cmp = icmp eq i32 %c, 0
  br i1 %cmp, label %ret1, label %ret2
ret1:
  ret i32 1
ret2:
  ret i32 2
}
优化后
define i32 @foo(i32 %c) {
  %cmp = icmp eq i32 %c, 0
  br i1 %cmp, label %ret1, label %ret2
ret1:
  br label %label_unified_ret
ret2:
  br label %label_unified_ret
label_unified_ret:
  %phi = phi i32 [1, %ret1], [2, %ret2]
  ret i32 %phi
}
