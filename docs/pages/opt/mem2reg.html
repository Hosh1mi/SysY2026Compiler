Mem2Reg

内存到寄存器提升 Pass，包含 SROA（标量替换）和标准 Mem2Reg 两个阶段，将 alloca 内存操作转化为 SSA 寄存器值和 phi 节点。

概览

Mem2Reg 执行两个阶段：

阶段功能
SROA将聚合类型（数组）alloca 拆分为标量 alloca
Mem2Reg将标量 alloca 提升为 SSA 寄存器 + phi 节点

Phase 1: SROA（标量替换）

SROA 将数组 alloca（如 alloca [10 x i32]）拆分为多个标量 alloca，前提是数组的所有访问都通过常量索引的 GEP 指令完成。

候选判定

  • alloca 类型为数组（ArrayTyID）
  • 每个直接使用者必须是 GEP 指令
  • GEP 结果类型必须是标量指针（i32/float）
  • 所有索引必须是编译期常量
  • GEP 的每个使用者必须是 Load 或 Store

变换

为每个唯一的常量索引元组创建独立的标量 alloca，将 GEP 的使用者重定向到新 alloca。相同索引的多个 GEP 共享同一个标量 alloca。

示例

优化前
  %arr = alloca [3 x i32]
  %p0 = getelementptr i32, [3 x i32]* %arr, 0, 0
  store i32 10, i32* %p0
  %p1 = getelementptr i32, [3 x i32]* %arr, 0, 1
  store i32 20, i32* %p1
  %v0 = load i32, i32* %p0
优化后
  %s0 = alloca i32    ; 索引 [0] 的标量
  %s1 = alloca i32    ; 索引 [1] 的标量
  store i32 10, i32* %s0
  store i32 20, i32* %s1
  %v0 = load i32, i32* %s0

Phase 2: Mem2Reg

将标量 alloca 的 load/store 内存操作转化为 SSA 寄存器值。

Alloca 可提升性判定

扫描所有 alloca 的使用者，只接受仅被 Load 和 Store 使用的情况。若 alloca 的地址被传给 GEP、call 等其他指令，则不可提升。

三种简单场景

场景条件处理
未使用 alloca无任何 load删除所有 store 和 alloca
单 store alloca恰好 1 个 storestore 支配所有 load 时，load 替换为 store 的值
单块 alloca所有使用在同一块按块内顺序，load 替换为最近前驱 store 的值

Phi 节点插入

对无法用简单场景处理的 alloca，通过迭代支配边界（IDF）计算 phi 插入位置：

  1. 定义块与 live-in 计算：defBlocks 包含 store 的块，liveInBlocks 包含"首 load 前无 store"的块
  2. 传播 live-in：BFS 向上扩展，遇到 def 块停止
  3. 迭代支配边界：从 defBlocks 出发，沿支配边界传播，仅在 live-in 块插入 phi

Rename（重命名）

沿支配树先序遍历，每个 alloca 维护一个值栈：

  1. 处理 phi：块开头的 phi 压入对应 alloca 的栈
  2. 重写 load：用栈顶值替换 load
  3. 重写 store：将 store 的值压入栈
  4. 填充后继 phi：为后继块的 phi 添加当前栈顶作为 incoming 值
  5. 递归子块：DFS 进入支配树子节点
  6. 恢复栈：退出时恢复栈深度，保证兄弟块隔离

示例

优化前
define i32 @foo(i32 %cond) {
entry:
  %x = alloca i32
  store i32 0, i32* %x
  br i1 %cond, label %then, label %else

then:
  store i32 1, i32* %x
  br label %merge

else:
  store i32 2, i32* %x
  br label %merge

merge:
  %v = load i32, i32* %x
  ret i32 %v
}
优化后
define i32 @foo(i32 %cond) {
entry:
  br i1 %cond, label %then, label %else

then:
  br label %merge

else:
  br label %merge

merge:
  %v = phi i32 [1, %then], [2, %else]
  ret i32 %v
}
