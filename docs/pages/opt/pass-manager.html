Pass 管理器

PassManager 负责注册、顺序执行所有优化 Pass， 并在每个 Pass 完成后通过 PreservedAnalyses 自动失效过期的分析缓存。 头文件 src/include/mid/opt/passManager.hpp。

Pass 接口

所有优化 Pass 继承自 Pass 基类，需要实现 execute() 和 name()。 基类提供了带 AnalysisManager 的默认重载，不需要分析的 Pass 只需实现无参版本。 

class Pass {
public:
    // 必须实现：不依赖分析的 Pass
    virtual void execute(Module *module) = 0;

    // 带 AnalysisManager 的版本，默认回退到无参 execute()
    // 需要分析的 Pass 重写此方法，返回 PreservedAnalyses
    virtual PreservedAnalyses execute(Module *module, AnalysisManager &AM) {
        (void)AM;
        execute(module);
        return PreservedAnalyses::none();  // 默认不保留任何分析
    }

    virtual std::string name() const = 0;
    virtual ~Pass() = default;
};

示例：实现一个简单 Pass

// 不需要分析的 Pass
class ConstantFold : public Pass {
public:
    void execute(Module *module) override;
    std::string name() const override { return "ConstantFold"; }
};

// 需要分析的 Pass（如依赖 LoopInfo）
class LICM : public Pass {
public:
    void execute(Module *module) override {}  // 不使用此版本
    PreservedAnalyses execute(Module *module, AnalysisManager &AM) override {
        for (auto func : module->function_list_) {
            if (func->is_declaration()) continue;
            LoopInfo &LI = AM.getLoopInfo(func);
            // ... 使用 LI 做循环不变代码外提 ...
        }
        PreservedAnalyses pa = PreservedAnalyses::none();
        pa.preserveLoopInfo();   // 不改变循环结构，保留 LoopInfo
        return pa;
    }
    std::string name() const override { return "LICM"; }
};

PassManager 类

PassManager 内部维护一个 vector<unique_ptr<Pass>> 队列， 调用 run() 时按注册顺序依次执行。 

class PassManager {
    std::vector<std::unique_ptr<Pass>> passes;
    AnalysisManager analyses_;
    bool dump_ir_    = false;
    bool verify_ir_  = false;
public:
    void addPass(std::unique_ptr<Pass> pass);
    void run(Module *module);

    void setDumpIR(bool v)   { dump_ir_   = v; }
    void setVerifyIR(bool v) { verify_ir_ = v; }
};

执行流程

run() 对每个 Pass 执行三步：

  1. dump_ir（可选）：打印 Pass 执行前的 IR
  2. execute：调用 pass->execute(module, analyses_)，获取 PreservedAnalyses
  3. invalidate：调用 analyses_.invalidate(module, preserved)，失效未保留的分析缓存
void PassManager::run(Module *module) {
    for (auto &pass : passes) {
        if (dump_ir_) {
            std::cerr << "; === IR Before " << pass->name() << " ===\n"
                      << module->print() << "\n";
        }

        PreservedAnalyses preserved = pass->execute(module, analyses_);

        if (verify_ir_) {
            module->verify();
        }

        analyses_.invalidate(module, preserved);

        if (dump_ir_) {
            std::cerr << "; === IR After " << pass->name() << " ===\n"
                      << module->print() << "\n";
        }
    }
}

流程图

addPass(Pass₁) → addPass(Pass₂) → ... → addPass(Passₙ)

run(Module):
  ┌─ Pass₁.execute(M, AM)
  │   → AM.invalidate(M, preserved₁)    ← 失效未保留的分析
  ├─ Pass₂.execute(M, AM)
  │   → AM.invalidate(M, preserved₂)
  └─ ...
  └─ Passₙ.execute(M, AM)
      → AM.invalidate(M, preservedₙ)

使用示例

基本用法

// 在 main.cpp 中构建并运行
PassManager pm;
pm.setDumpIR(options.dumpIR);
pm.setVerifyIR(options.verifyIR);

// 注册 Pass（顺序很重要）
pm.addPass(std::make_unique<CFGSimplify>());
pm.addPass(std::make_unique<Mem2Reg>());
pm.addPass(std::make_unique<EarlyCSE>());
pm.addPass(std::make_unique<DeadCodeDelete>());

// 执行所有 Pass
pm.run(module);

调试选项

// --dump-ir：在每个 Pass 前后打印 IR（输出到 stderr）
// 输出示例：
// ; === IR Before Mem2Reg ===
// define i32 @main() { ... }
// ; === IR After Mem2Reg ===
// define i32 @main() { ... }

// --verify-ir：在每个 Pass 后调用 module->verify()
// 检查 IR 一致性（类型匹配、use-def 链完整等），失败时 abort

与 AnalysisManager 的协作

PassManager 内置一个 AnalysisManager 实例， 在每次 execute() 调用时传递给 Pass。Pass 可以按需获取分析结果， 并在完成后通过返回 PreservedAnalyses 声明哪些分析仍然有效。 

// Pass 声明保留的分析 → AM 不失效其缓存
PreservedAnalyses pa = PreservedAnalyses::none();
pa.preserveLoopInfo();   // 循环结构未变 → 保留 LoopInfo
pa.preserveSCEV();       // SCEV 表达式未变 → 保留 SCEV
return pa;
// AM 只会失效 BasicAA（未声明保留的）

// Pass 不声明保留 → AM 失效所有分析缓存
return PreservedAnalyses::none();  // 所有分析下次使用时重新计算
设计要点

PassManager 是线性流水线，不支持 Pass 嵌套或条件执行。 Pass 之间的执行顺序在 buildOptimizationPipeline() 中静态确定， 详见 优化流水线。
