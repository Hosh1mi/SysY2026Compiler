Reassociate

再结合优化 Pass，展平加法树并应用代数变换：加法转乘法、A+(-A) 消除、公共因子提取。

概览

Reassociate 对 Add 和 Mul 指令展平操作树，按 rank 排序后应用三种优化。仅处理 Add 指令（Mul 仅用于因子提取）。

优化规则

规则变换说明
加法转乘法X+X+X → 3*X相同操作数合并为乘法
自反消除A+(-A) → 0识别 sub 0, X 模式
公共因子提取A*B+A*C → A*(B+C)从 Mul 树中提取最高频因子

算法流程

  1. Rank 计算：按 BB 顺序分配 rank，常量 rank=0，参数 rank 低，指令 rank 随位置递增
  2. 展平操作树：沿单使用链递归收集同操作码的叶子操作数
  3. 常量规范化：常量始终放在右侧
  4. 按 rank 降序排序：相同值聚集，便于匹配
  5. 依次应用三种优化：仅在确实产生优化时修改，否则保留原指令

因子提取

对展平后的 Add 操作数中的 Mul 指令，提取所有单使用因子并统计频率。出现次数最多的因子被提取为公因子。

removeFactor 从 Mul 树中移除目标因子，支持负号匹配（X 和 -X 可互匹配，结果取反）。

示例

公共因子提取
; 优化前
  %t1 = mul i32 %a, %b
  %t2 = mul i32 %a, %c
  %s  = add i32 %t1, %t2

; 优化后
  %inner = add i32 %b, %c
  %s     = mul i32 %inner, %a
