GlobalScalarPromotion

将整数标量全局变量提升为函数局部 alloca，消除跨调用的内存访问开销。

概览

对于只存储整数标量且在函数内无 call 指令的全局变量，将其提升为 entry 块的 alloca，在函数入口加载初始值，在 ret 前写回最终值，中间所有对全局变量的 load/store 重定向到局部 alloca。

适用条件

  • 全局变量类型为整数（i32）
  • 函数内不含 call 指令（保证不会被其他函数修改）
  • 全局变量的所有使用都是 load 或 store

变换过程

  1. 收集：扫描模块中所有整数标量全局变量
  2. entry 加载初始化：在函数 entry 块创建 alloca，并用 load + store 初始化
  3. ret 前回写：在每个 ret 指令前插入 store，将最终值写回全局变量
  4. 重定向：函数内所有对全局变量的 load/store 重定向到局部 alloca
