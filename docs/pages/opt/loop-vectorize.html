LoopVectorize

循环向量化 Pass，将简单循环体展开为 VF=4 的向量操作，生成向量化主循环 + 标量尾部循环。

概览

LoopVectorize 识别简单的单步循环（单位步长 IV、连续内存访问、纯算术运算），将其变换为每轮处理 4 个元素的向量化循环，并保留标量尾部循环处理剩余迭代。

常量

名称值含义
VECTORIZE_FACTOR4每轮处理元素数
useVectorIRtrue启用向量 IR（而非标量展开）

向量化条件

  1. 循环必须有 preheader 和唯一 exit
  2. 循环体 ≤ 2 个基本块
  3. 存在单位步长归纳变量（stride = ±1）
  4. 无非 IV phi（累加器等跨迭代依赖）
  5. 所有内存访问是 GEP + IV 索引的连续访存
  6. 所有指令可向量化（无 call、alloca、SDiv/SRem）
  7. 别名分析安全：NoAlias 或同地址 read-before-write

向量化变换

模式 A：全向量化 IR

适用于纯 load-binop-store 循环（IV 不参与运算）：

  • GEP + Bitcast 生成向量指针
  • Load 生成 <4 x i32> 向量加载
  • BinaryInst 生成向量运算
  • Store 生成向量存储
  • 循环不变操作数在 preheader 中 Splat

模式 B：标量展开 + 向量打包

当 IV 参与运算或存在非 IV phi 时：

  1. 为每个 offset j ∈ [0, VF) 克隆循环体指令
  2. 收集同基址的 4 个 store，按 offset 排序
  3. 检测 store 值的根 binop，将两个操作数分别打包为向量
  4. 创建向量 binop + 向量 store 替换标量版本

向量 IV Phi

对于 IV 参与运算的场景，创建向量 phi <0,1,2,3> + 增量 <4,4,4,4>，在循环中维护向量化 IV。

尾部循环

向量化主循环处理 N - (N % VF) 次迭代，剩余迭代由原循环改造的标量尾部循环处理。主循环的 bound 调整为 bound - (VF-1)。

迭代策略

变换后 CFG 改变，需重新计算支配信息和循环。最多迭代 5 次，每次变换后重新分析。

示例

模式 A：纯 load-binop-store 向量化

对应源语言 for (int i = 0; i < N; i++) A[i] = B[i] + C[i];，循环体只有标量 load/add/store：

优化前
header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %gep_b = getelementptr i32, i32* %B, i32 %iv
  %vb = load i32, i32* %gep_b
  %gep_c = getelementptr i32, i32* %C, i32 %iv
  %vc = load i32, i32* %gep_c
  %sum = add i32 %vb, %vc
  %gep_a = getelementptr i32, i32* %A, i32 %iv
  store i32 %sum, i32* %gep_a
  %cmp = icmp slt i32 %iv, %N
  br %cmp, label %latch, label %exit

latch:
  %iv.next = add i32 %iv, 1
  br label %header
优化后（向量化主循环，VF=4）
vec_preheader:
  %splat_n = insertelement <4 x i32> undef, i32 %N, i32 0
  %bound_n = shufflevector <4 x i32> %splat_n, <4 x i32> undef, <4 x i32> zeroinitializer
  br label %vec_header

vec_header:
  %vec_iv = phi <4 x i32> [<0,1,2,3>, %vec_preheader], [%vec_iv.next, %vec_latch]
  %gep_b_v = getelementptr i32, i32* %B, <4 x i32> %vec_iv  ; 向量 GEP
  %vb_v = load <4 x i32>, <4 x i32>* %gep_b_v              ; 向量 load
  %gep_c_v = getelementptr i32, i32* %C, <4 x i32> %vec_iv
  %vc_v = load <4 x i32>, <4 x i32>* %gep_c_v              ; 向量 load
  %sum_v = add <4 x i32> %vb_v, %vc_v                       ; 向量 add
  %gep_a_v = getelementptr i32, i32* %A, <4 x i32> %vec_iv
  store <4 x i32> %sum_v, <4 x i32>* %gep_a_v               ; 向量 store
  %vec_iv.next = add <4 x i32> %vec_iv, <4,4,4,4>            ; IV += VF
  %cmp_v = icmp slt <4 x i32> %vec_iv.next, %bound_n
  br %cmp_v, label %vec_latch, label %scalar_tail

vec_latch:
  br label %vec_header

主循环每轮处理 4 个元素，剩余迭代由标量尾部循环处理。

模式 B：IV 参与运算时的标量展开 + 向量打包

对应 for (int i = 0; i < N; i++) A[i] = B[i] * i;，其中 IV 参与乘法运算：

优化前
header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %gep_b = getelementptr i32, i32* %B, i32 %iv
  %vb = load i32, i32* %gep_b
  %prod = mul i32 %vb, %iv          ; IV 参与运算
  %gep_a = getelementptr i32, i32* %A, i32 %iv
  store i32 %prod, i32* %gep_a
  ...
  br %cmp, label %latch, label %exit
优化后（标量展开 + 向量打包）
vec_header:
  %vec_iv = phi <4 x i32> [<0,1,2,3>, %pre], [%vec_iv.next, %vec_latch]

  ; 标量展开：为每个 offset 克隆计算
  %iv_0 = extractelement <4 x i32> %vec_iv, i32 0   ; i
  %iv_1 = extractelement <4 x i32> %vec_iv, i32 1   ; i+1
  %iv_2 = extractelement <4 x i32> %vec_iv, i32 2   ; i+2
  %iv_3 = extractelement <4 x i32> %vec_iv, i32 3   ; i+3

  ; ... 分别计算 4 个标量 mul ...

  ; 打包为向量 store
  %prod_v0 = insertelement <4 x i32> undef, i32 %prod_0, i32 0
  %prod_v1 = insertelement <4 x i32> %prod_v0, i32 %prod_1, i32 1
  %prod_v2 = insertelement <4 x i32> %prod_v1, i32 %prod_2, i32 2
  %prod_v3 = insertelement <4 x i32> %prod_v2, i32 %prod_3, i32 3
  store <4 x i32> %prod_v3, <4 x i32>* %gep_a_v

  %vec_iv.next = add <4 x i32> %vec_iv, <4,4,4,4>
  ...
  br %cmp_v, label %vec_latch, label %scalar_tail

由于 IV 参与运算，无法直接生成向量 GEP，改为标量展开后 insertelement 打包。
