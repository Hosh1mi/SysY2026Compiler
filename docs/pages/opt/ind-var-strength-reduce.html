IndVarStrengthReduce

归纳变量强度削弱 Pass，将循环内的乘除计算转换为加法，降低指令开销。

概览

IndVarStrengthReduce 识别循环中依赖归纳变量（IV）的派生计算（如 A[i*N+k] 中的 GEP），将其替换为指针 phi + 步进 GEP，将每次迭代的乘法运算削弱为一次加法。

基本 IV 识别

findBasicIVs 扫描 header phi，识别形如 phi(init, add/sub(X, stride)) 的 SSA 基本归纳变量：

  • phi 类型为 i32
  • 一个 incoming 来自循环外（init），一个来自循环内（update）
  • update 是 add/sub，且一个操作数通过 phi 链归结为 phi 自身，另一个是循环不变常量

SCEV 线性化

linearizeSCEVForIV 将 ScalarEvolution 表达式线性化为 coeff * IV + offset 的形式：

  • 常量 → constOffset
  • IV phi → coeff=1
  • Add → 各项 coeff 相加
  • Mul → 仅支持一个 IV 项与常量相乘
  • 循环不变量 → offset

GEP 候选筛选

对循环内每个 GEP，检查其索引是否恰好有一个依赖 IV：

  • 所有索引通过 SCEV 线性化
  • 恰好一个索引含 IV 分量（coeff ≠ 0）
  • 初始表达式可在 preheader 中物化

变换过程

对每个 GEP 候选：

  1. 计算 effectiveStride = iv.stride × elemStride × coeff
  2. 在 preheader 中创建初始 GEP（各索引用初始值物化）
  3. 在 header 创建指针 phi：incoming = [initGEP, preheader], [incrGEP, latch]
  4. 在 latch 创建步进 GEP：gep(addrPhi, effectiveStride)
  5. 原 GEP 替换为 addrPhi

安全限制

  • 函数中不含数组 alloca（避免栈数组干扰）
  • 循环只有一个回边前驱
  • 循环中无向量操作（避免与向量化的寄存器冲突）
  • 所有索引必须是 i32 类型

示例

二维数组访问的强度削弱

对应源语言 for (int i = 0; i < N; i++) sum += A[i][k];，其中 A[i][k] 的 GEP 含 i * COLS 乘法：

优化前
header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %base = mul i32 %iv, 10            ; i * COLS，每次迭代一次乘法
  %idx = add i32 %base, %k           ; i * COLS + k
  %gep = getelementptr i32, i32* %A, i32 %idx
  %val = load i32, i32* %gep
  %sum = add i32 %sum_prev, %val
  %cmp = icmp slt i32 %iv, %N
  br %cmp, label %latch, label %exit

latch:
  %iv.next = add i32 %iv, 1
  br label %header
优化后
preheader:
  %init_gep = getelementptr i32, i32* %A, i32 %k   ; 初始地址 = &A[0][k]
  br label %header

header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %addr = phi i32* [%init_gep, %preheader], [%incr_gep, %latch]  ; 指针 phi
  %val = load i32, i32* %addr                       ; 直接用指针访问，无乘法
  %sum = add i32 %sum_prev, %val
  %cmp = icmp slt i32 %iv, %N
  br %cmp, label %latch, label %exit

latch:
  %iv.next = add i32 %iv, 1
  %incr_gep = getelementptr i32, i32* %addr, i32 10   ; addr += COLS，每次只加步进
  br label %header

收益：循环内每次迭代的 mul i32 %iv, 10 被替换为 gep +10（一次加法），将乘法运算削弱为加法。

effectiveStride 计算过程

以 A[i * 3 + k] 为例（coeff=3，元素大小=4 字节）：

  • IV stride = 1（i 每次 +1）
  • SCEV 线性化：idx = 3 * i + k，所以 coeff = 3
  • elemStride = 1（GEP 索引是 i32 级，非字节级）
  • effectiveStride = iv.stride × elemStride × coeff = 1 × 1 × 3 = 3
  • 指针 phi 每步递增 3 个 i32 元素
