LoopRepFold

循环重复折叠 Pass，识别“外层计数 + 内层累加”模式，将重复迭代的累加合并为一次乘法。

概览

LoopRepFold 识别一种特殊的嵌套循环：外层是计数 IV（r_phi: 0 → N），内层是累加器（total_phi），且累加器的每次外层迭代增量相同。此时可将 N 次迭代的累加折叠为一次乘法。

识别条件

  1. header 恰好有 2 个 phi：计数 IV（r_phi）和累加器（total_phi）
  2. r_phi：初始值=0，每次 latch += 1
  3. 循环条件：icmp slt r_phi, N，N 循环不变
  4. 循环体内无 store、无 call（保证每次 r 迭代计算结果相同）
  5. total_latch 不依赖计数 IV（每次迭代的增量相同）

变换过程

折叠公式

total_final = total_init + (total_latch - total_init) × N

当 total_init == 0 时简化为 total_latch × N。

  1. 在 latch 的 terminator 前插入 total_final 计算
  2. 重定向 latch 跳转目标：从 header 改为 loop_exit
  3. 删除 header phi 中来自 latch 的 incoming
  4. 在 loop_exit 插入 phi：[total_phi, header], [total_final, latch]

支配树实现

本 Pass 自实现支配树计算（RPO + Cooper-Harvey-Kennedy 迭代算法），不依赖外部 DominatorInfo。

示例

“外层计数 + 内层累加”模式折叠

对应源语言逻辑：外层循环计数 r 从 0 到 N，内层每次累加相同的结果 delta：

优化前
header:
  %r = phi i32 [0, %preheader], [%r.next, %latch]     ; 计数 IV
  %total = phi i32 [0, %preheader], [%total.l, %latch] ; 累加器
  %cmp = icmp slt i32 %r, %N
  br %cmp, label %body, label %exit

body:
  ; ... 计算 delta（不依赖 %r，每次结果相同）
  %total.l = add i32 %total, %delta
  ...
  br label %latch

latch:
  %r.next = add i32 %r, 1
  br label %header

exit:
  ; 使用 %total
优化后
header:
  ; 循环只执行一次（不迭代 N 次）
  %r = phi i32 [0, %preheader], [%r.next, %latch]
  %total = phi i32 [0, %preheader], [%total.l, %latch]
  %cmp = icmp slt i32 %r, %N
  br %cmp, label %body, label %exit

body:
  %total.l = add i32 %total, %delta
  ...
  br label %latch

latch:
  %r.next = add i32 %r, 1
  ; 折叠计算：total_final = total + delta * N
  %total_final = add i32 %total, (mul i32 %delta, %N)
  br label %exit                               ; 重定向到 exit，不再回 header

exit:
  %total_out = phi i32 [%total, %header], [%total_final, %latch]
  ; 使用 %total_out

收益：原循环需执行 N 次迭代，优化后只执行 1 次，剩余 N-1 次的累加结果通过一次乘法计算。

关键约束解释

为什么要求“total_latch 不依赖计数 IV”？

  • 若 delta 不依赖 r，则每次外层迭代的增量相同，折叠为 delta × N 正确
  • 若 delta 依赖 r（如 delta = r * 2），则不同迭代的增量不同，无法简单乘以 N
