CFGSimplify

控制流图简化 Pass，通过多种局部变换减少基本块数量和冗余分支，为后续 SSA 相关 Pass 提供更干净的 CFG。

概览

CFGSimplify 对每个函数反复执行以下四个子变换，直到不再变化（不动点）：

子变换功能触发条件
Diamond → Select将 if-else 菱形结构折叠为 select 指令条件分支的两个目标汇合到同一块，且 phi 可替换
常量分支折叠将条件为常量的 br 变为无条件跳转br 的条件操作数是 ConstantInt
空块合并消除仅含无条件跳转的中间基本块块内只有一条无条件 br 指令
不可达块删除删除无前驱的非入口块非入口块且 pre_bbs_ 为空

执行流程

CFGSimplify::execute — 不动点迭代
void CFGSimplify::execute(Module *module) {
    for (auto *func : module->function_list_) {
        if (func->is_declaration()) continue;
        bool changed = true;
        while (changed) {
            changed = false;
            changed |= convertDiamondsToSelect(func);
            changed |= foldConstantBranches(func);
            std::vector<BasicBlock *> bbs(func->basic_blocks_.begin(),
                                          func->basic_blocks_.end());
            for (auto *bb : bbs)
                if (bb->parent_ == func)
                    changed |= mergeEmptyBlock(bb);
            removeDeadBlocks(func);
        }
    }
}

每个子变换都可能暴露新的简化机会：例如常量分支折叠后产生空块，空块合并后产生不可达块，因此需要循环迭代直到不动点。

1. Diamond → Select 转换

识别 if-else 菱形控制流模式，将分支 + phi 替换为无分支的 select 指令。支持三种模式：

Pattern A：双边中间块

两个分支路径都有中间块，最终汇合到同一个 merge 块：

Pattern A 结构
// condBB → trueBB → mergeBB
// condBB → falseBB → mergeBB
// trueBB 和 falseBB 都只有一条无条件 br 到 mergeBB

Pattern B：If-then（仅 true 路径有中间块）

Pattern B 结构
// condBB → trueBB → mergeBB (= falseBB)
// falseBB 本身就是 merge 块

Pattern C：If-else（仅 false 路径有中间块）

Pattern C 结构
// condBB → falseBB → mergeBB (= trueBB)
// trueBB 本身就是 merge 块

变换过程

变换分五步完成：

  1. 模式识别：检查 condBB 的终止指令是否为条件 br，条件是否为 icmp 且仅被 br 使用一次
  2. 中间指令克隆：将中间块的指令（必须是安全的纯计算指令）克隆到 condBB 中 br 之前
  3. 创建 select：用 select icmp, trueVal, falseVal 替代分支
  4. 更新 phi：如果 phi 只有 2 个前驱，直接用 select 替换 phi；否则原地更新 phi 的入边
  5. 替换分支：删除 condBB 的条件 br，改为无条件跳转到 mergeBB

安全性检查

中间块的指令必须满足"可推测执行"条件，即无论条件真假都安全执行：

isSafeToSpeculate — 不允许的指令类型
static bool isSafeToSpeculate(Instruction *inst) {
    if (inst->is_load())  return false;   // 可能触发段错误
    if (inst->is_store()) return false;   // 副作用
    if (inst->is_call())  return false;   // 副作用
    if (inst->is_div())   return false;   // 可能除零
    if (inst->is_rem())   return false;   // 可能除零
    if (inst->is_ret())   return false;   // 终止指令
    if (inst->is_br())    return false;   // 终止指令
    return true;  // add, sub, mul, icmp, select 等安全
}

Merge 块下沉

当 merge 块仅剩 ret 指令且所有 phi 都已无使用者时，可将 ret 下沉到 condBB，消除多余跳转：

Merge 块下沉示例
// 下沉前：condBB → br mergeBB; mergeBB → ret %sel
// 下沉后：condBB → ret %sel （mergeBB 被删除）

示例

优化前 — SysY 源码
int max(int a, int b) {
    int result;
    if (a > b)
        result = a;
    else
        result = b;
    return result;
}
优化前 — IR
define i32 @max(i32 %a, i32 %b) {
label_entry:
  %cmp = icmp sgt i32 %a, %b
  br i1 %cmp, label %then, label %else

then:
  br label %merge

else:
  br label %merge

merge:
  %result = phi i32 [ %a, %then ], [ %b, %else ]
  ret i32 %result
}
优化后 — IR
define i32 @max(i32 %a, i32 %b) {
label_entry:
  %cmp = icmp sgt i32 %a, %b
  %result = select i1 %cmp, i32 %a, i32 %b
  ret i32 %result
}

两个中间块 then 和 else 被消除，phi 被 select 替换，控制流从三分支变为直线代码。

2. 常量分支折叠

当条件分支的条件操作数在编译期已知为常量时，将条件 br 替换为无条件 br，跳转到确定的目标块。

变换过程

  1. 遍历所有基本块的终止指令
  2. 如果是三操作数 br（条件分支），检查条件操作数是否为 ConstantInt
  3. 根据常量值选择目标块：非零跳 true 分支，零跳 false 分支
  4. 调用 replaceBranchWithUncond：
    • 清理被抛弃目标块中引用此块的 phi 入边
    • 移除两条旧 CFG 边
    • 删除条件 br，创建无条件 br

示例

优化前 — SysY 源码
int foo() {
    int x;
    if (1)       // 条件恒为真
        x = 42;
    else
        x = 0;
    return x;
}
优化前 — IR（常量传播后）
define i32 @foo() {
label_entry:
  br i1 1, label %then, label %else

then:
  br label %merge

else:
  br label %merge

merge:
  %x = phi i32 [ 42, %then ], [ 0, %else ]
  ret i32 %x
}
常量分支折叠后 — IR
define i32 @foo() {
label_entry:
  br label %then          ; 无条件跳转到 then

then:
  br label %merge

else:                      ; 不可达，后续会被删除
  br label %merge

merge:
  %x = phi i32 [ 42, %then ]   ; else 入边已被清除
  ret i32 %x
}

else 块变为不可达，会在后续的不可达块删除中被清除。随后空块合并会进一步将 then 合并掉。

3. 空块合并

消除仅包含一条无条件跳转的"透传"基本块，将其前驱直接连接到目标块。

前置条件

一个基本块必须同时满足以下所有条件才能被合并：

  • 不是函数入口块
  • 块内恰好只有一条指令（即终止指令本身）
  • 该指令是无条件 br（单操作数）
  • 不是自环（目标不是自身）
  • 没有前驱同时已经是目标块的前驱（避免 phi 歧义）

变换过程

  1. Phi 修复：如果目标块有 phi 节点，将被合并块的入边重定向到其所有前驱
  2. 前驱重定向：将所有前驱的分支目标从被合并块改为目标块（支持无条件 br 和条件 br）
  3. 删除空块：清除指令并从函数中移除

边界情况处理

无前驱块

如果被合并块没有前驱（如 TailRecursionEliminate 产生的孤立 preheader），需额外检查目标块的 phi 是否引用此块。若引用则不能合并，否则 phi 入边会丢失。

共享前驱检查

如果某个前驱 P 既指向被合并块 B，又直接指向目标块 T，合并后 P 会在 T 的 phi 中产生两条入边，且两条入边的值可能不同，造成语义歧义。此时跳过合并。

示例

优化前 — IR
define i32 @bar(i32 %x) {
label_entry:
  %cmp = icmp sgt i32 %x, 0
  br i1 %cmp, label %mid, label %done

mid:                       ; 空块，仅含无条件跳转
  br label %done

done:
  %r = phi i32 [ 1, %mid ], [ 0, %label_entry ]
  ret i32 %r
}
优化后 — IR
define i32 @bar(i32 %x) {
label_entry:
  %cmp = icmp sgt i32 %x, 0
  br i1 %cmp, label %done, label %done   ; mid 被跳过

done:
  %r = phi i32 [ 1, %label_entry ], [ 0, %label_entry ]  ; mid→label_entry
  ret i32 %r
}

mid 块被消除，phi 中原本 [1, %mid] 的入边被重定向为 [1, %label_entry]（mid 的唯一前驱）。

4. 不可达块删除

删除所有从入口块不可达的基本块。使用工作表算法级联传播：删除一个块后，如果其后继块失去最后一个前驱，也变为不可达。

算法

removeDeadBlocks — 工作表级联删除
static void removeDeadBlocks(Function *func) {
    auto *entry = getEntryBlock(func);
    std::queue<BasicBlock *> worklist;
    // 初始：收集所有无前驱的非入口块
    for (auto *bb : func->basic_blocks_)
        if (bb != entry && bb->pre_bbs_.empty())
            worklist.push(bb);
    while (!worklist.empty()) {
        auto *bb = worklist.front(); worklist.pop();
        auto succs = bb->succ_bbs_;
        for (auto *succ : succs) {
            removeBBFromPhi(bb, succ);         // 清除 phi 入边
            succ->remove_pre_basic_block(bb);  // 移除前驱
            if (succ != entry && succ->pre_bbs_.empty())
                worklist.push(succ);           // 级联：后继也变为不可达
        }
        // 删除块及其指令
        for (auto *inst : bb->instr_list_) bb->delete_instr(inst);
        bb->parent_->remove_bb(bb);
    }
}

示例

常量分支折叠后产生的不可达块
; 常量分支折叠后，else 块不再有任何前驱
define i32 @foo() {
label_entry:
  br label %then

then:
  br label %merge

else:                      ; 无前驱 → 不可达
  br label %merge

merge:
  %x = phi i32 [ 42, %then ]
  ret i32 %x
}
不可达块删除后
define i32 @foo() {
label_entry:
  br label %then

then:
  br label %merge

merge:
  %x = phi i32 [ 42, %then ]
  ret i32 %x
}

else 块被级联删除，其对 merge 的 phi 入边也被清除。
