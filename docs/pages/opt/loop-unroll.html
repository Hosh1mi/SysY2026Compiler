LoopUnroll

循环展开 Pass，将小循环体复制 UF=4 次以减少分支开销和循环控制开销。

概览

LoopUnroll 将简单循环的 latch 体复制 N 次（默认 UF=4），生成一个主循环（每轮处理 N 次迭代）和一个尾部循环（处理剩余迭代）。

常量

名称值含义
UNROLL_FACTOR4默认展开因子
MAX_LATCH_INSTS8latch 体最大指令数（超过则不展开）

展开条件

  1. 循环恰好 2 个基本块（header + latch）
  2. 有唯一 preheader 和唯一 exit
  3. 存在整数 IV：phi(init, add/sub(phi, const_stride))
  4. 循环条件是 icmp + IV + 循环不变 bound
  5. latch 无 call / phi / alloca
  6. latch 体 ≤ MAX_LATCH_INSTS 条指令
  7. bound ≥ (UF-1) × stride（避免下溢）

寄存器压力估计

4× 展开会为每个 header phi 创建 4 条交错的 SSA 链。当循环同时有整数累加器 phi 和 ≥2 个指针 phi（来自 IVSR）时，寄存器分配器无法着色所有交错活跃范围，导致累加器 spill。此时将展开因子降低为 2。

变换过程

  1. 调整边界：boundMain = bound - (UF-1) × stride
  2. 创建 headerMain：为每个 header phi 创建对应的主循环 phi
  3. 复制 latch 体：在 unrolledBody 中复制 N 次 latch 指令，使用 iterMap 链接迭代间数据
  4. 回边：unrolledBody 无条件跳回 headerMain
  5. 主循环条件：headerMain 中 iv < boundMain 则进 unrolledBody，否则进原 header（尾部循环）
  6. phi 修复：原 header phi 的 preheader incoming 改为来自 headerMain
  7. CFG 重连：preheader 跳转到 headerMain

示例

UF=4 循环展开

对应源语言 for (int i = 0; i < N; i++) A[i] = A[i] + 1;，一个典型的 header + latch 二块循环：

优化前
preheader:
  br label %header

header:
  %iv = phi i32 [0, %preheader], [%iv.next, %latch]
  %gep = getelementptr i32, i32* %A, i32 %iv
  %val = load i32, i32* %gep
  %add = add i32 %val, 1
  store i32 %add, i32* %gep
  %cmp = icmp slt i32 %iv, %N
  br %cmp, label %latch, label %exit

latch:
  %iv.next = add i32 %iv, 1
  br label %header
优化后（UF=4）
preheader:
  %bound_main = sub i32 %N, 3              ; N - (UF-1)*stride = N - 3
  br label %header_main

header_main:                               ; 主循环 header
  %iv_main = phi i32 [0, %preheader], [%iv_main_next, %unrolled_body]
  %cmp_main = icmp slt i32 %iv_main, %bound_main
  br %cmp_main, label %unrolled_body, label %header  ; 进展开体或尾部循环

unrolled_body:                             ; 4 次迭代交错展开
  ; --- 迭代 0: iv_main ---
  %gep_0 = getelementptr i32, i32* %A, i32 %iv_main
  %val_0 = load i32, i32* %gep_0
  %add_0 = add i32 %val_0, 1
  store i32 %add_0, i32* %gep_0

  ; --- 迭代 1: iv_main + 1 ---
  %iv_1 = add i32 %iv_main, 1
  %gep_1 = getelementptr i32, i32* %A, i32 %iv_1
  %val_1 = load i32, i32* %gep_1
  %add_1 = add i32 %val_1, 1
  store i32 %add_1, i32* %gep_1

  ; --- 迭代 2: iv_main + 2 ---
  %iv_2 = add i32 %iv_main, 2
  %gep_2 = getelementptr i32, i32* %A, i32 %iv_2
  %val_2 = load i32, i32* %gep_2
  %add_2 = add i32 %val_2, 1
  store i32 %add_2, i32* %gep_2

  ; --- 迭代 3: iv_main + 3 ---
  %iv_3 = add i32 %iv_main, 3
  %gep_3 = getelementptr i32, i32* %A, i32 %iv_3
  %val_3 = load i32, i32* %gep_3
  %add_3 = add i32 %val_3, 1
  store i32 %add_3, i32* %gep_3

  %iv_main_next = add i32 %iv_main, 4      ; IV += UF
  br label %header_main

header:                                    ; 尾部循环（原循环）
  %iv = phi i32 [%iv_main, %header_main], [%iv.next, %latch]
  %gep = getelementptr i32, i32* %A, i32 %iv
  %val = load i32, i32* %gep
  %add = add i32 %val, 1
  store i32 %add, i32* %gep
  %cmp = icmp slt i32 %iv, %N
  br %cmp, label %latch, label %exit

latch:
  %iv.next = add i32 %iv, 1
  br label %header

收益：主循环每轮处理 4 次迭代，分支开销降低到 1/4。尾部循环处理剩余 0~3 次迭代。

寄存器压力降低 UF 的场景

当循环同时有整数累加器 phi 和 ≥2 个指针 phi（来自 IVSR）时：

  • 4× 展开会创建 4 条交错的 SSA 链，寄存器压力翻倍
  • 寄存器分配器无法同时着色所有活跃范围，导致 spill
  • 此时 Pass 自动将 UF 降为 2，以平衡循环开销和寄存器压力
