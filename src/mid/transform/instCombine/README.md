# InstCombine 说明

## 总体作用

InstCombine（Instruction Combining，指令组合）是一个工作列表驱动的局部优化 Pass。它检查单条指令或由少量相邻指令组成的表达式，把它们改写成语义等价、结构更简单或更适合后端生成代码的形式。

它主要完成以下工作：

- 常量折叠：在编译期计算操作数均为常量的表达式。
- 代数化简：消除零元、单位元、自抵消和重复运算。
- 指令组合：把连续的加减、乘除、移位、位运算或类型转换合并。
- 强度削弱：用代价较低的运算替换代价较高的运算，例如把乘以二次幂改为移位。
- 表达式规范化：统一交换律操作数、比较谓词和 `select` 的形式，便于后续 Pass 继续匹配。
- 事实推导：利用已知符号范围、二次幂、整除性、无回绕等信息，执行需要额外证明的安全化简。
- 向量折叠：逐 lane 折叠常量向量，并简化向量插入、抽取和重排操作。

InstCombine 只做能够证明语义等价的局部改写，不负责完整的全局优化：

- 不负责跨大范围表达式树的全局重结合，这类工作由 Reassociate 等 Pass 处理。
- 不负责一般性的公共子表达式消除，这类工作由 CSE/GVN 类 Pass 处理。
- 不负责系统性删除所有死指令；成功替换后遗留的死代码可由 DCE 清理。
- 通常不改变 CFG，只会在严格支配条件下把仅被一条指令使用的纯指令下沉到使用位置。

## 工作流程

`instCombine.cpp` 先把函数中的现有指令加入工作列表，然后按操作码调用对应的 `visit*` 函数：

1. 从工作列表取出一条仍然存活的非终结指令。
2. 根据操作码分派到加减、乘除余、移位、位运算、比较、转换或向量处理函数。
3. `visit*` 返回一个等价替代值；无法安全化简时返回 `nullptr`。
4. 成功时先保存使用旧值的指令和旧指令的操作数，再替换全部 use 并删除旧指令。
5. 将受影响的使用者指令、替代指令和操作数重新加入工作列表，继续迭代到局部定点。
6. 若某个操作数在替换后只被另一基本块中的一条指令使用，并满足支配和无副作用要求，则尝试把该操作数的定义下沉到使用者指令之前。

为防止病态表达式导致编译时间失控，驱动器同时限制处理次数和成功改写次数。范围分析只在首次 IR 改写前使用；发生改写后立即清除相关缓存，避免继续使用引用旧指令的过期事实。

## 各文件作用

| 文件 | 主要职责 |
| --- | --- |
| `instCombine.cpp` | InstCombine 的总驱动器。遍历函数、维护工作列表、按操作码分派、替换旧值、删除旧指令、重新调度受影响节点，并在安全条件满足时下沉纯指令。 |
| `instCombineInternal.hpp` | 各子模块共享的内部接口和辅助逻辑。包含常量识别与构造、表达式形状比较、二次幂判断、已知符号/倍数/位信息推导、语义标记传播，以及所有 `visit*` 函数声明。 |
| `instCombineAddSub.cpp` | 整数和浮点加减法化简。处理常量折叠、零元消除、负号抵消、公共项消除、连续常量合并、加减互换，以及 `fneg` 等浮点形式。 |
| `instCombineMulDivRem.cpp` | 整数/浮点乘除和有符号取余化简。处理零与单位元、二次幂强度削弱、嵌套乘除常量合并、符号与范围证明、有界余数修正，并保护后续循环优化需要识别的循环携带余数。 |
| `instCombineShifts.cpp` | `shl`、`lshr`、`ashr` 化简。处理零移位、常量移位、连续移位合并、移位与掩码组合，并检查位宽、符号扩展和移位量范围。 |
| `instCombineBitwise.cpp` | `and`、`or`、`xor` 化简。处理全零/全一恒等式、自抵消、吸收律、互补模式、常量重结合，以及基于已知位互不重叠事实的改写。 |
| `instCombineCmpSelect.cpp` | `icmp`、`fcmp` 和 `select` 的主要规范化模块。负责交换比较操作数与谓词、常量比较、布尔比较消除、范围辅助证明、整数/浮点比较折叠、相同分支消除，以及 min/max 类选择模式。 |
| `instCombineCompares.cpp` | 比较指令的跨表达式辅助折叠。目前重点处理比较两侧的常量加减，例如把 `icmp (x + C1), C2` 改写为对 `x` 与调整后常量的比较，并用宽整数检查防止常量调整溢出。 |
| `instCombineCast.cpp` | 类型转换和 PHI 的局部折叠。处理 `zext`、整数/浮点转换、`bitcast`、`clz` 的常量或冗余转换，并删除所有入值相同的退化 PHI。 |
| `instCombineVector.cpp` | 向量指令化简。逐 lane 折叠向量常量算术，处理零向量/单位向量恒等式，并简化 `insertelement`、`extractelement`、`shufflevector`、广播和恒等重排。 |

## 模块之间的关系

`instCombine.cpp` 是唯一的调度中心，其他 `.cpp` 文件不独立遍历 IR，而是实现供驱动器调用的局部访问函数。`instCombineInternal.hpp` 是这些实现之间的共享层。

典型调用关系如下：

```text
InstCombine::runOnFunction
        |
        +-- Add/Sub/FAdd/FSub/FNeg ------> instCombineAddSub.cpp
        +-- Mul/SDiv/SRem/FMul/FDiv -----> instCombineMulDivRem.cpp
        +-- Shl/LShr/AShr ----------------> instCombineShifts.cpp
        +-- And/Or/Xor -------------------> instCombineBitwise.cpp
        +-- ICmp/FCmp/Select -------------> instCombineCmpSelect.cpp
        |                                      |
        |                                      +-- foldICmpAddSub
        |                                          instCombineCompares.cpp
        +-- Cast/Clz/Phi ------------------> instCombineCast.cpp
        +-- 向量算术/插入/抽取/重排 ------> instCombineVector.cpp

所有子模块共享 instCombineInternal.hpp 中的常量、事实推导和构造辅助函数。
```

## 常见化简示例

以下示例只展示典型形式，实际应用还会检查类型、位宽、溢出、符号范围和 use 关系：

```text
x + 0                  -> x
x - x                  -> 0
x * 1                  -> x
x * 8                  -> x << 3
x / 1                  -> x
x & 0                  -> 0
x | 0                  -> x
x ^ x                  -> 0
(x << 2) << 3          -> x << 5
select cond, a, a      -> a
extract(insert(v,x,i),i) -> x
phi [x, bb1], [x, bb2] -> x
```

## 正确性注意事项

- 有符号整数变换不能默认溢出不存在；需要依赖常量范围、RangeAnalysis 或明确的无回绕事实。
- 除法和取余化简必须处理除零、负数、有符号余数语义及 `INT_MIN / -1` 等边界情况。
- 移位量必须位于合法位宽内，算术右移与逻辑右移不能混用。
- 浮点改写不能直接套用所有整数代数恒等式，需要考虑 NaN、无穷大和有符号零。
- 向量化简必须保证所有 lane 类型和数量一致；任一 lane 无法安全折叠时，不能提交部分常量结果。
- 新建替代指令后必须放在其所有 use 之前；跨基本块移动还必须满足支配关系。
- 替换和删除指令必须通过 IR 提供的接口维护 use-list，不能只修改裸操作数或指令链表。
